## 项目简介

**模拟面试智能体系统**是一款创新型的 AI 驱动面试训练平台，专为求职者和职场人士设计。系统深度融合**计算机视觉**、**情感计算**与**大语言模型（LLM）** 等前沿技术，为用户提供沉浸式、智能化的模拟面试体验。

### 项目背景

在传统面试准备过程中，求职者面临以下痛点：
- 缺乏真实面试环境模拟
- 难以自我察觉肢体语言问题（如姿态不当、眼神交流不足）
- 无法客观评估面部表情与情绪状态
- 缺少个性化反馈和学习路径指导
- 简历与岗位匹配度分析缺失

本系统通过 AI 分析技术，为用户提供全方位、量化的面试能力评估和改进建议。

### 目标用户

- 应届毕业生（高职、本科、研究生、博士）
- 寻求职业发展的职场人士
- 准备跳槽的专业技术人员
- 希望提升面试能力的学习者

### 核心价值

1. **真实模拟**：还原真实面试场景，支持实时视频交互
2. **智能分析**：多维度 AI 分析（肢体动作、微表情、情绪）
3. **个性反馈**：基于岗位需求的定制化评估报告
4. **持续改进**：学习路径推荐 + 历史数据追踪

## 功能特性

### 核心功能

#### 1. 用户管理系统
- 用户注册/登录（支持账号密码认证）
- 个人信息管理（学校、专业、学历、年级等）
- 头像上传（支持 JPG/PNG/GIF/WebP 格式）
- 简历上传与管理（PDF 格式）
- 用户状态追踪（头像/简历上传状态）

#### 2. 智能面试系统
- **实时视频面试**：低延迟实时视频交互
- **自适应提问**：根据简历和回答动态生成面试问题
- **多轮对话**：支持完整的面试流程（自我介绍→专业问题→综合评估）
- **岗位定制**：支持大数据、物联网、人工智能等多个领域

#### 3. AI 智能分析
- **肢体动作分析**：姿态识别、手势动作、身体语言智能评估
- **微表情分析**：面部表情识别、眼神接触追踪、情绪状态分析

#### 4. 智能评测报告
- **多维度量化评分**：核心能力雷达图评估
- **结构化综合评语**：详细优点总结、可操作改进建议、岗位匹配度分析
- **精准总体评分**：0-100 分专业评估

#### 5. 学习路径推荐
- 基于面试表现的个性化资源推荐
- 薄弱环节针对性训练建议
- 行业发展趋势和技能培训方向

#### 6. 报告管理
- 历史报告查询、详情查看
- 报告下载（PDF/JSON 格式）

## 技术架构

系统采用分层架构设计，包含前端层、API网关层、业务服务层、AI引擎层和数据持久层，保障系统的高可用、高性能与易扩展。

### 技术栈

#### 后端核心
- 高性能异步 Web 框架：FastAPI
- 数据库：MySQL 8.0+
- 异步服务支持，保障高并发处理能力

#### AI 技术栈
- 计算机视觉：MediaPipe、OpenCV、DeepFace
- 大语言模型：Qwen Spark4.0
- 深度学习框架：TensorFlow、PyTorch
- LLM 应用开发：LangChain

#### 核心能力
- 实时视频流处理
- 多模态数据并行分析（肢体 + 表情）
- 大模型工作流智能编排
- 高效文件处理与数据管理
