# 模拟面试服务系统 - 课程项目汇报PPT设计方案

## 项目概述

**项目名称**：模拟面试服务系统（InterviewSystem）
**项目性质**：课程实践项目 · 教学演示系统
**课程目标**：综合运用AI技术、Web开发、系统架构等知识，完成完整项目开发实践
**核心技术栈**：FastAPI · WebSocket · YOLO视觉分析 · ASR语音识别 · LLM大语言模型 · MySQL

---

| 设计元素 | 规范要求 |

### 2.5 核心技术架构页（第7-9页）

**第7页：技术选型概览**

**核心内容要点**：
- **后端框架**：FastAPI（高性能异步框架）
- **通信协议**：WebSocket（实时双向通信）
- **数据库**：MySQL（关系型数据存储）
- **AI服务**：
  - 计算机视觉：YOLOv8（目标检测）
  - 语音识别：ASR（自动语音转写）
  - 大语言模型：阿里云通义千问（Qwen系列）
- **部署**：Docker容器化

**建议图表类型**：
- 技术栈金字塔或架构图

**第8页：系统架构设计**

**核心内容要点**：
- **架构分层**：
  - 接入层：Web客户端
  - 服务层：FastAPI应用服务器
  - 业务层：面试服务、用户管理、题库管理
  - AI层：视频分析、语音识别、LLM评估
  - 数据层：MySQL数据库、文件存储
- **模块调用关系与数据流向**

**建议图表类型**：
- 系统架构图：层级框图+连接线
- 数据流图：箭头+标注

**第9页：Agent智能体架构与技术整合**

**核心内容要点**：
- **Agent智能体设计**：

  - YOLOv8视觉分析集成（眼神接触、肢体语言检测）

  - WebSocket实时通信（视频流、音频流传输）

### 3.2 PPT制作工具推荐

1. **Microsoft PowerPoint**：传统专业，功能全面
2. **WPS演示**：轻量级，模板丰富
3. **Keynote**：Mac专属，设计感强
4. **Canva**：在线协作，模板多样
5. **Gamma.app**：AI辅助生成，自动化程度高

### 3.4 演示注意事项

1. **演讲时间控制**：建议总时长15-20分钟
2. **重点突出**：每页只讲1-2个核心要点
3. **互动设计**：可准备演示视频或现场演示环节
4. **备份准备**：准备PDF版本以防技术故障
5. **提前调试**：投影效果、字体显示、动画流畅度
