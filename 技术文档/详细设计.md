## 一、系统概述
### 1.1 项目背景
传统面试准备存在以下核心痛点：
- 缺乏真实视频面试环境
- 无法客观观察肢体、表情、眼神等非语言行为问题
- 缺少实时、量化、结构化的反馈机制
- 练习成本高、反馈主观、效率低

本系统基于多模态 AI（计算机视觉 CV + 自动语音识别 ASR + 大语言模型 LLM）技术，提供一站式模拟面试解决方案。

### 1.2 系统目标
- 提供高还原度的实时视频模拟面试环境
- 自动分析面试者肢体、眼神、情绪、语音等多维度表现
- 支持 AI 动态出题与多轮智能对话
- 自动生成结构化、可视化的评测报告
- 支持面试历史记录、复盘分析、数据统计功能

### 1.3 目标用户
- 应届毕业生
- 职场求职者
- 技术岗位面试者
- 高校就业指导/实训教学场景

### 1.4 技术栈
| 分类       | 技术选型 |
|------------|----------|
| 后端       | Python 3.9+、FastAPI、SQLAlchemy |
| 数据库     | MySQL 8.0+ |
| AI 框架    | MediaPipe（姿态）、DeepFace（情绪）、Whisper（语音）、讯飞星火（LLM） |
| 通信       | WebSocket、WebRTC |
| 部署       | Nginx、Gunicorn、本地文件存储 |

## 三、模块详细设计
### 3.1 用户管理模块
#### 3.1.1 核心功能
- 用户注册、登录、JWT 身份认证
- 个人信息（学校、专业、学历等）维护
- 头像、简历文件上传与管理
- 权限控制（普通用户 / 管理员）

#### 3.1.2 数据库表设计（users）
| 字段名     | 说明                |
|------------|---------------------|
| accountID  | 主键，用户唯一标识  |
| password   | BCrypt 加盐加密存储 |
| nickName   | 用户昵称            |
| schoolName | 学校名称            |
| major      | 所学专业            |
| qualification | 学历           |
| grade      | 年级/毕业年份       |
| birthday   | 出生日期            |
| avatar     | 是否上传头像（布尔）|
| resume     | 是否上传简历（布尔）|
| createTime | 账号创建时间        |

#### 3.1.3 接口设计
| 方法 | 接口路径                | 功能         |
|------|-------------------------|--------------|
| POST | /api/users/register     | 用户注册     |
| POST | /api/users/login        | 用户登录（返回 7 天有效期 JWT） |
| PUT  | /api/users/update       | 更新个人信息 |
| GET  | /api/users/{accountID}  | 获取用户信息 |

#### 3.1.4 安全机制
- 密码：BCrypt 加盐加密
- 接口：JWT 鉴权 + 角色拦截
- 文件：头像/简历文件权限隔离存储

### 3.2 题库管理模块
#### 3.2.1 核心功能
- 题库多级分类：领域 → 岗位
- 题目增删改查、上下线状态管理
- 难度分级：简单、中等、困难
- 智能组卷：破冰题 → 专业题 → 压力题 → 开放题

#### 3.2.2 数据库表设计
按领域分表（bigdata / internetofthings / ai），表结构统一：
| 字段名 | 说明           |
|--------|----------------|
| ID     | 题目主键       |
| degree | 难度等级       |
| question | 题目内容    |
| answer | 参考回答       |

#### 3.2.3 接口设计
| 方法 | 接口路径                          | 功能                 |
|------|-----------------------------------|----------------------|
| GET  | /api/questions/{job}/{degree}     | 获取指定岗位/难度题目 |
| POST/PUT/DELETE | /api/admin/questions | 管理员题目管理（增删改） |
| POST | /api/admin/questions/batch        | 批量导入/导出题目    |

### 3.3 视频面试模块
#### 3.3.1 核心流程
```plaintext
用户选择岗位 → WebSocket 建立连接 → AI 发送首题 → 
前端 WebRTC 采集视频（12 秒切片上传）→ 后端保存视频片段 →
音频提取 + ASR 语音识别 → LLM 分析回答生成下一题 →
循环多轮对话 → 面试结束 → 合并完整视频 →
调用 AI 多模态分析 → 生成评测报告
```

#### 3.3.2 WebSocket 接口
- 路径：/interview/ws
- 连接参数：id（用户ID）、date（面试时间）、resume（简历标识）、selected_job（目标岗位）
- 通信内容：文本（题目）+ 二进制（视频流）

#### 3.3.3 视频处理规范
- 采集格式：WebM
- 切片规则：12 秒/段
- 后端处理：合并所有切片为 MP4 格式存储

### 3.4 AI 多模态分析模块
#### 3.4.1 姿态分析（MediaPipe）
- 识别维度：坐姿、低头、叉腰、双手紧握、正常
- 输出：姿态得分、针对性评语

#### 3.4.2 眼神检测
- 识别维度：注视摄像头时长、眼神游离次数
- 输出：眼神得分、专注度评价

#### 3.4.3 情绪识别（DeepFace）
- 识别维度：7 种基础情绪（angry/disgust/fear/happy/sad/surprise/neutral）
- 输出：情绪分布、情绪稳定性、自信度评分

#### 3.4.4 语音分析（Whisper）
- 识别维度：语速、流畅度、语调
- 输出：语音评分、流畅度评语

#### 3.4.5 智能提问（讯飞星火 LLM）
- 输入：用户简历 + 历史对话记录
- 输出：动态适配题目、难度自适应调整

#### 3.4.6 统一输出格式
```json
{
  "pose": {
    "score": 0-100,
    "comment": "姿态评语",
    "detail": "姿态识别详情"
  },
  "eye_contact": {
    "score": 0-100,
    "focus_duration": "注视时长",
    "distract_count": "游离次数",
    "comment": "专注度评语"
  },
  "emotion": {
    "distribution": {"angry": 0.0, ..., "neutral": 1.0},
    "stability": 0-100,
    "confidence": 0-100,
    "comment": "情绪评语"
  },
  "speech": {
    "speed": "语速（字/分钟）",
    "fluency": 0-100,
    "tone": "语调评价",
    "score": 0-100,
    "comment": "语音评语"
  },
  "overall_score": 0-100
}
```

### 3.5 报告生成模块
#### 3.5.1 报告结构
- 核心指标：总分（0-100）
- 可视化维度：雷达图（专业、逻辑、表达、自信、情绪、肢体）
- 详细内容：各维度评分、情绪曲线、姿态/眼神数据、语音分析、综合评语、改进建议

#### 3.5.2 生成流程
```plaintext
汇总 AI 各模块结果 → 加权计算总分 → LLM 生成个性化评语/建议 → 组装报告结构
```

#### 3.5.3 输出格式
- 数据库存储：JSON 格式
- 用户下载：PDF 格式
- 前端展示：可视化交互页面

### 3.6 数据统计模块
#### 3.6.1 个人统计
- 面试次数、平均分、成绩趋势图
- 岗位匹配度分析、能力雷达图

#### 3.6.2 系统统计
- 总面试次数、AI 调用次数、面试成功率
- 服务器性能监控（响应时间、资源占用）

### 3.7 管理员后台模块
#### 3.7.1 核心功能
- 题库管理（增删改查、批量操作）
- 用户管理（账号状态、权限调整）
- 系统日志（操作日志、错误日志）
- 系统配置（AI 接口参数、视频存储规则）

#### 3.7.2 权限控制
- JWT 鉴权 + 角色字段拦截（仅管理员角色可访问）

## 五、接口设计总览
### 5.1 REST API
| 模块       | 接口路径                                  | 方法 | 功能                     |
|------------|-------------------------------------------|------|--------------------------|
| 用户管理   | /api/users/register                       | POST | 注册                     |
| 用户管理   | /api/users/login                          | POST | 登录（返回 JWT）         |
| 用户管理   | /api/users/update                         | PUT  | 更新信息                 |
| 用户管理   | /api/users/{accountID}                    | GET  | 获取用户信息             |
| 题库管理   | /api/questions/{job}/{degree}             | GET  | 获取指定岗位/难度题目    |
| 面试报告   | /api/interview/report/{reportID}          | GET  | 获取单份评测报告         |
| 面试报告   | /api/interview/reports/history/{accountID}| GET  | 获取面试历史报告         |

### 5.2 WebSocket 接口
- 路径：/interview/ws
- 握手参数：id、date、resume、selected_job
- 通信流程：握手 → AI 发题 → 前端传视频流 → ASR 识别 → LLM 生成下一题 → 循环 → 面试结束

### 5.3 第三方接口
- 讯飞星火 LLM（主）：智能出题、评语生成
- 备用 LLM（可选）：容灾备份
- Whisper ASR：语音转文字

## 六、AI 引擎设计
### 6.1 模块组成
- 姿态分析模块（MediaPipe）
- 眼神检测模块
- 情绪识别模块（DeepFace）
- 语音识别/分析模块（Whisper）
- 大语言模型模块（讯飞星火）

### 6.2 并行处理机制
视频帧拆分后并行分发至各 AI 分析模块，模块独立计算，最终聚合分析结果。

### 6.3 调用流程
```plaintext
面试视频 → 帧拆分 → 姿态/眼神/情绪并行分析 + 音频提取→ASR→语音分析 → 结果聚合 → 报告生成
```

## 九、安全设计
1. 密码安全：BCrypt 加盐加密存储
2. 认证安全：JWT 鉴权 + 角色拦截
3. 文件安全：视频/简历/头像权限隔离，过期自动清理
4. 接口安全：防越权、防 SQL 注入
5. 数据安全：敏感信息脱敏存储
