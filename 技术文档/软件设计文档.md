**后端核心模块**：

#### 用户管理模块
- **路由**: `user_router.py`
- **服务**: `OrdServices` 中用户相关方法
- **功能**: 用户注册、登录（JWT签发）、信息查询与更新、头像简历管理

#### 面试题库管理模块
- **路由**: `question_router.py`
- **服务**: `OrdServices` 中题目相关方法
- **功能**: 按岗位（大数据/物联网/AI）和难度查询题目，支持题库规模管理

#### 模拟面试模块 (核心)
- **路由**: `interview_router.py`（WebSocket端点）
- **服务**: `InterviewService`
- **技术特点**: WebSocket实时通信、异步处理、视频片段分割、线程池评测
- **主要流程**: 建立连接→发送开场问题→接收视频→ASR转录→LLM生成问题→循环→生成评测报告

#### 分析与评测模块
- **服务**: `Body_Emotion`
- **分析维度**: 身体姿态、情绪识别、眼神接触、手部移动、身体移动、言语流畅度/语速/语调
- **输出**: 多维度评分 + 个性化学习推荐

#### AI助手模块
- **路由**: `ai_router.py`
- **技术**: 集成讯飞Spark大模型，支持多轮对话

#### 文件管理模块
- **路由**: `download_router.py`、`check_resume`
- **存储结构**: `/DataFile/{Resume|Avatar|Video|Reports}/`
- **支持格式**: 头像(JPG/PNG/GIF/WebP)、简历(PDF)、视频(WebM/MP4)

### 1.4 AI与中间服务架构设计

**AI分析引擎核心能力**：
- 视频帧并行分发：将输入视频流按帧拆分，并行分发给各分析模块
- 结果聚合：收集各模块输出，整合为统一格式的评测报告数据
- 模型加载器：统一管理深度学习模型（MediaPipe、DeepFace、YOLOv8）的加载与释放
- LLM调用：通过讯飞Spark大模型API实现智能提问生成和综合评语生成

**数据存储服务**：
- MySQL数据库：用户数据、面试记录、评测报告持久化存储
- 文件存储：视频文件、简历、头像、PDF报告的本地文件系统管理
- 缓存服务（可选）：热点数据如题库、用户信息的内存缓存

### 2.2 用户管理功能

#### FR-UM-001 账号注册
- **功能描述**: 支持用户填写基本信息完成注册流程
- **业务规则**: 前端校验数据格式，后端检查账号唯一性，密码BCrypt加密后存入数据库
- **流程**: 用户填写注册信息 → 前端校验 → 后端验证唯一性 → 密码加密存储 → 可选上传头像和简历 → 注册成功

#### FR-UM-002 账号登录
- **功能描述**: 支持用户名密码登录，实现身份认证
- **业务规则**: 后端验证密码匹配性，登录成功生成JWT Token（有效期7天），后续请求携带Token验证身份
- **流程**: 输入用户名密码 → 后端验证 → 生成JWT Token → 返回用户信息

#### FR-UM-003 个人中心
- **功能描述**: 提供个人信息管理和数据概览功能
- **流程**: 查看和修改个人信息 → 上传/更换头像和简历 → 展示面试数据统计概览

#### FR-UM-004 权限控制
- **功能描述**: 基于角色的访问控制（RBAC），防止越权操作
- **业务规则**: JWT Token解析用户角色，拦截器校验接口访问权限，普通用户仅访问自身相关接口，管理员可访问题库管理、用户管理等专属接口

### 2.3 面试题目管理功能

#### FR-QM-001 题库分类管理
- **功能描述**: 支持多级分类体系（领域→岗位）和分类全生命周期管理
- **业务规则**: 多级分类（领域为一级，岗位为二级），管理员可新增/编辑/删除分类，支持上下线操作，删除前校验是否被题目引用

#### FR-QM-002 题目属性管控
- **功能描述**: 管理题目基本属性和多维度筛选
- **业务规则**: 题目属性包含岗位ID、难度、内容、答案、标签，支持按岗位、难度、标签筛选

#### FR-QM-003 智能组卷
- **功能描述**: 根据岗位自动生成面试题目序列
- **业务规则**: 用户选择岗位后从题库抽取题目，难度梯度为破冰题→专业题→压力题→开放题，确保考察维度覆盖全面，支持随机打乱顺序

#### FR-QM-004 题库运维操作
- **功能描述**: 支持题库的批量运维和操作审计
- **业务规则**: 支持批量导入导出（Excel/CSV），题目上下线管理，操作日志记录

### 2.4 在线面试与评测功能

#### FR-IM-001 实时视频面试
- **功能描述**: WebSocket实时音视频交互，AI自动提问互动
- **核心流程**: 前端请求摄像头权限并建立WebSocket连接 → 按帧率捕获视频流发送至后端 → AI生成第一道问题并返回 → 用户作答时持续发送视频流 → ASR转录回答 → 大模型分析后生成下一题 → 达到指定轮数或用户主动结束

#### FR-IM-002 面试过程录制
- **功能描述**: 全程录制面试视频并安全存储
- **核心流程**: WebSocket连接建立后开始录制 → 切片存储（每30秒一片段） → 面试结束后合并为完整视频 → 设置访问权限和自动清理周期

#### FR-IM-003 本地评测调用
- **功能描述**: 异步调用AI分析程序进行多维度评测
- **核心流程**: 用户提交面试后创建评测任务 → 异步调用AI分析程序 → 前端轮询进度（0%-100%） → 完成后触发报告生成

#### FR-IM-004 自动化评测流程
- **功能描述**: 多模态AI分析肢体、眼神、手部、情绪等维度
- **核心流程**: 肢体动作（识别关键点，分析坐姿/姿态/手势）→ 眼神接触（统计注视摄像头时长占比）→ 手部移动（计算手势丰富度和自然度）→ 情绪识别（分析七种基本情绪，绘制变化曲线）→ 汇总各维度计算得分

#### FR-IM-005 提交记录留存
- **功能描述**: 完整保存面试记录和评测结果
- **核心流程**: 保存评测状态和各维度得分 → 生成分析报告（评语、建议、雷达图） → 记录视频回放路径 → 保存问答记录 → 数据持久化支持历史查询

### 2.5 AI智能辅助功能

#### FR-AI-001 肢体动作分析
- **功能描述**: 识别人体姿态并评价肢体语言质量
- **核心流程**: 视频帧预处理和关键点检测 → 计算坐姿端正度、姿态稳定性、手势动作指标 → 根据阈值和评分规则计算得分 → 生成结构化评语

#### FR-AI-002 眼神接触检测
- **功能描述**: 统计眼神交流情况并评价专注度
- **核心流程**: 检测瞳孔和眼角坐标 → 计算视线方向向量 → 统计眼神接触时长、游离次数 → 结合行业基准计算得分并生成评语

#### FR-AI-003 情绪状态识别
- **功能描述**: 识别面部表情并分析情绪稳定性
- **核心流程**: 抽取关键帧并分析七种情绪概率分布 → 构建情绪时间序列 → 计算情绪稳定性、自信度、积极性指标 → 生成情绪分析报告和评语

#### FR-AI-004 智能提问生成
- **功能描述**: 基于大模型动态生成面试问题
- **核心流程**: 根据岗位和简历选择首题 → ASR转录用户回答 → 调用大模型分析回答质量并生成下一题 → 动态调整难度 → 确保问题覆盖多个考察维度

#### FR-AI-005 综合评测报告生成
- **功能描述**: 生成多维度量化评估报告和个性化建议

| 属性 | 值 |
|------|-----|
| **端点** | `/interview/ws` |
| **协议** | WebSocket |
| **认证** | 否 (Query参数验证) |
| **描述** | 建立实时面试WebSocket连接 |

**连接参数** (Query String):
```
ws://host:port/interview/ws?id=user123&date=2025-07-09%2000:00:00&resume=/path/to/resume.pdf&selected_job=bigdata
```

| 参数 | 类型 | 必需 | 说明 |
|------|------|-----|------|
| `id` | string | ✓ | 用户账号ID |
| `date` | string | ✓ | 面试日期时间 (格式: YYYY-MM-DD HH:MM:SS) |
| `resume` | string | ✓ | 简历文件路径 |
| `selected_job` | string | ✓ | 面试岗位 (bigdata/internetofthings/ai) |

**WebSocket 消息格式**:

接收消息 (二进制):
```
WebM格式的视频流数据 (VP8/VP9 + Vorbis/Opus)
12秒为一个完整片段
```

发送消息 (文本):
```
"请简单做一下自我介绍"
"根据您的简历，请介绍一下XXX项目的技术架构"
"面试结束，感谢您的参与！您的评测报告已生成，reportID: 12345"
```

**连接流程**:
1. 建立连接后，立即接收第一个问题
2. 持续发送视频流数据 (WebM格式)
3. 12秒无数据时，自动超时结束该片段
4. 接收下一个问题或面试结束信号
5. 循环直到面试结束

**可能的错误**:
- `400`: 缺少必需参数
- `500`: 服务器内部错误

##### 业务服务层与AI引擎层接口

**接口描述**: 业务服务层调用AI分析能力的标准接口

**数据格式**:
```json
{
  "task_type": "pose_analysis|emotion_detection|full_report",
  "video_path": "/DataFile/Video/user123/video_001.webm",
  "accountID": "user123",
  "reportID": 12345
}
```

**返回格式**:
```json
{
  "status": "completed|processing|failed",
  "progress": 85,
  "result": { }
}
```

##### 业务服务层与数据持久层接口

**接口描述**: 业务服务层访问数据存储的标准接口

**功能封装**:
- ORM数据访问：通过SQLAlchemy执行数据库CRUD操作
- 事务管理：涉及多表操作时启用事务，支持回滚机制
- 文件存储接口：封装文件读写操作，统一路径管理和权限控制
- 缓存接口：热点数据（如题库、用户信息）缓存至内存，提升查询性能

##### AI引擎内部模块间接口

**接口描述**: AI引擎内部各分析模块间的协作接口

**模块协作**:
1. 视频帧分发器：将输入视频流按帧拆分，并行分发给肢体分析、情绪识别等模块
2. 结果聚合器：收集各分析模块的输出，整合为统一格式的报告数据
3. 模型加载器：统一管理深度学习模型的加载和释放，避免重复占用内存

##### WebSocket视频流传输接口

**接口描述**: 前后端通过WebSocket实现实时视频流传输

**通信流程**:
1. 连接建立：前端发起WebSocket连接请求，携带面试ID和用户Token
2. 身份验证：后端校验Token有效性，拒绝非法连接
3. 视频帧发送：前端按固定频率（15-30fps）发送编码后的视频帧
4. 心跳检测：双方定期发送Ping/Pong消息维持连接活跃
5. 断线重连：网络异常时前端自动尝试重连，恢复上下文

##### WebSocket面试问题推送接口

**接口描述**: 后端通过WebSocket实时推送面试问题给前端

**通信流程**:
1. 初始问题下发：连接建立后，后端发送第一道面试问题
2. 动态问题推送：根据用户回答质量，实时推送下一道问题
3. 面试结束通知：达到指定轮数或用户主动结束时发送终止消息
4. 错误处理：传输失败时重试或降级为文本展示

**接口描述**: 调用讯飞星火大模型实现智能问答生成

### 5.3 异常处理流程

| 异常类型 | 触发条件 | 处理方案 |
|---------|--------|--------|
| 数据库连接失败 | 数据库离线 | 返回500错误，记录日志 |
| 文件上传超大 | 文件>限制大小 | 返回413错误，提示用户 |
| 文件格式错误 | 非允许格式 | 返回400错误，拒绝上传 |
| WebSocket连接中断 | 网络问题 | 停止录制，后台清理资源 |
| 视频处理失败 | FFmpeg处理出错 | 记录日志，标记为失败 |
| ASR识别失败 | 语音模块错误 | 使用默认问题/重试 |
| LLM服务不可用 | AI服务离线 | 使用本地题库备选方案 |
| 报告生成超时 | 后台处理超时 | 异步继续处理，通知用户 |

#### 6.1.1 HTTP基础设置

| 属性 | 值 | 说明 |
|------|-----|-----|
| 协议版本 | HTTP/1.1 | 标准HTTP协议 |

#### 6.1.2 请求格式

**通用请求头**:
```
Content-Type: application/json
Authorization: Bearer {JWT_Token}  # 如果需要认证
Accept: application/json
Accept-Encoding: gzip, deflate
Connection: keep-alive
```

**请求方法**:
- GET: 查询数据
- POST: 创建数据
- PUT: 更新数据
- DELETE: 删除数据

**示例 - 用户注册**:
```
POST /api/users/register
Content-Type: multipart/form-data

{
  "user_data_json": "{\"accountID\":\"user123\",\"password\":\"pwd123\",\"nickName\":\"张三\",...}",
  "avatar_file": [文件],  // 可选
  "resume_file": [文件]   // 可选
}
```

---

#### 6.1.3 响应格式

**统一响应结构**:
```json
{
  "code": 200,
  "message": "请求成功",
  "data": {
    // 具体数据内容
  }
}
```

**状态码定义**:

| 状态码 | 含义 | 场景 |
|--------|------|------|
| 200 | 成功 | 请求处理成功 |
| 201 | 已创建 | 用户注册成功 |
| 400 | 客户端错误 | 参数验证失败、文件格式错误 |
| 401 | 未认证 | 登录失败、Token过期 |
| 403 | 禁止访问 | 权限不足 |
| 404 | 资源不存在 | 用户不存在、报告不存在 |
| 413 | 请求体过大 | 文件上传超大 |
| 500 | 服务器错误 | 数据库错误、处理异常 |
| 503 | 服务不可用 | AI服务离线 |

### 6.2 WebSocket通信协议

#### 6.2.1 WebSocket基础信息

| 属性 | 值 | 说明 |
|------|-----|------|
| 协议 | WebSocket (ws://) | 实时双向通信 |
| 数据格式 | 二进制/文本混合 | 视频流(二进制) + 问题(文本) |
| 连接URL | ws://host:port/interview/ws | - |
| 连接参数 | Query String | id, date, resume, selected_job |
| 超时时间 | 12秒 | 无数据接收超时 |

---

#### 6.2.2 WebSocket连接参数

```
GET /interview/ws?id=user123&date=2025-07-09%2000:00:00&resume=/path/to/resume.pdf&selected_job=bigdata HTTP/1.1
Upgrade: websocket
Connection: Upgrade
```

| 参数 | 类型 | 必需 | 说明 |
|------|------|-----|------|
| id | String | ✓ | 用户账号ID |
| date | String | ✓ | 面试日期时间(格式: YYYY-MM-DD HH:MM:SS) |
| resume | String | ✓ | 简历文件路径 |
| selected_job | String | ✓ | 面试岗位(bigdata, internetofthings, ai) |

#### 6.4.1 认证方案

- **方案**: JWT (JSON Web Token)
- **签发**: 用户登录成功后签发
- **有效期**: 24小时 (可配置)
- **刷新机制**: 支持Token刷新端点

**JWT Token结构**:
```
Header: {
  "alg": "HS256",
  "typ": "JWT"
}

Payload: {
  "sub": "user123",        // subject (accountID)
  "exp": 1234567890,       // expiration time
  "iat": 1234567800,       // issued at
  "role": "user"           // user role
}

Signature: HMACSHA256(base64(header) + "." + base64(payload), secret)
```
