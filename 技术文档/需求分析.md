# 模拟面试智能体系统 - 需求分析文档

## 一、项目概述

### 1.1 项目背景与目标

针对传统面试准备中缺乏真实环境模拟、难以自我察觉肢体/表情问题、缺少个性化量化反馈等痛点，依托多模态 AI 技术（计算机视觉、情感计算、大语言模型），打造沉浸式智能化模拟面试平台。系统实现实时视频面试交互、肢体动作智能分析、微表情识别、情绪状态监测、多维度量化评估、个性化改进建议生成等核心功能，为应届毕业生、职场人士、技术人员提供高效、智能的面试能力提升解决方案。

### 1.2 核心业务流程

用户注册登录→完善个人信息→上传简历（可选）→选择面试岗位→进入视频面试→AI 实时提问互动→面试过程全程录制→AI 分析肢体动作/眼神接触/情绪状态→生成多维度评测报告→查看历史面试记录→针对性改进训练

### 1.3 用户角色划分

**• 普通用户**：注册登录、个人信息管理、简历上传、模拟面试、查看评测报告、历史面试回放、下载面试报告

**• 管理员**：题库管理（增删改查）、岗位分类维护、用户管理、系统参数配置、评测日志查看

## 二、功能需求

### 2.1 用户管理模块

**•2.1.1 账号注册**：
  - 用户访问注册页面，填写用户名、密码、确认密码、邮箱、学校、专业、学历等必填信息
  - 系统前端校验数据格式（邮箱格式、密码强度等），校验通过后提交至后端
  - 后端检查账号 ID 唯一性，若已存在则返回错误提示；若唯一则对密码进行 BCrypt 加密处理
  - 创建用户记录并写入数据库，默认角色为普通用户，账号状态为正常
  - 支持用户上传头像和简历文件，文件存储至指定目录并更新用户记录中的头像/简历标识
  - 注册成功后自动登录或跳转至登录页面

**•2.1.2 账号登录**：
  - 用户输入用户名和密码，提交登录请求
  - 后端根据用户名查询用户记录，验证密码匹配性（BCrypt 解密比对）
  - 验证账号状态是否正常，若被禁用则拒绝登录并提示原因
  - 登录成功后生成 JWT Token，设置有效期（如 7 天），返回给前端保存
  - 后续请求需在 Header 中携带 Token，中间件验证 Token 有效性及权限
  - Token 过期需重新登录或刷新 Token

**•2.1.3 个人中心**：
  - 用户登录后查看个人信息，包括昵称、学校、专业、学历、年级、生日等
  - 支持修改基本信息，提交后后端校验数据合法性并更新至数据库
  - 支持上传/更换头像：选择图片文件→前端预览→上传至服务器→存储路径更新至用户记录
  - 支持上传/更新简历：选择 PDF 文件→上传至服务器→解析简历内容（可选）→存储路径更新
  - 展示个人面试数据统计概览（总次数、平均分、能力趋势图等）

**•2.1.4 权限控制**：
  - 系统基于角色划分权限：普通用户仅可访问自身相关接口，管理员可访问管理接口
  - 后端通过 JWT Token 解析用户角色，拦截器校验接口访问权限
  - 禁止越权操作：普通用户尝试访问管理员接口时返回 403  Forbidden
  - 管理员专属接口包括：题库管理、岗位分类维护、用户管理、系统参数配置等

### 2.2 面试题目管理模块

**•2.2.1 题库分类管理**：
  - 系统支持多级分类体系：一级分类为领域（大数据、物联网、人工智能等），二级分类为岗位（Java 开发、前端工程师、数据分析师等）
  - 每个岗位可绑定多个领域标签，支持灵活组合
  - 管理员可新增领域/岗位分类，填写名称、描述等信息
  - 支持编辑现有分类信息，调整领域与岗位的关联关系
  - 支持删除分类（需校验是否被题目引用，若有引用则禁止删除）
  - 支持分类上下线操作，下线分类对用户不可见

**•2.2.2 题目属性管控**：
  - 每道题目包含以下属性：唯一题目标识、所属岗位 ID、难度等级（简单/中等/困难）、问题内容、参考答案、考察维度标签
  - 管理员新增题目时需选择所属岗位、设置难度、填写问题和答案
  - 支持为题目添加多个标签（如"沟通能力"、"逻辑思维"、"专业技能"等），便于后续组卷和评测
  - 题目列表支持按岗位、难度、标签等多维度筛选和搜索

**•2.2.3 智能组卷**：
  - 用户选择面试岗位后，系统根据岗位 ID 从题库中抽取题目
  - 组卷策略：按难度梯度组织题目序列，包含破冰题（简单，1-2 题）→专业能力题（中等，3-5 题）→压力测试题（困难，1-2 题）→开放性问题（中等，1-2 题）
  - 题目抽取考虑标签覆盖度，确保考察维度全面（沟通、逻辑、专业、应变等）
  - 支持随机打乱题目顺序，避免固定模式
  - 面试过程中可根据用户回答质量动态调整后续题目难度

**•2.2.4 题库运维操作**：
  - 管理员可对题目进行新增、编辑、删除操作
  - 支持批量导入题目（Excel/CSV 格式），系统自动解析并校验数据格式
  - 支持批量导出题目，便于备份和迁移
  - 支持题目上下线操作，下线题目不参与组卷
  - 操作日志记录：谁在何时对哪些题目进行了什么操作

### 2.3 在线面试与评测模块

**•2.3.1 实时视频面试**：
  - 用户进入面试界面，系统请求摄像头和麦克风权限
  - 权限授予后，前端建立 WebSocket 连接至后端面试服务
  - 前端按固定帧率（如 15fps）捕获视频流，分片编码后通过 WebSocket 发送至后端
  - 后端接收视频流并实时存储为视频文件（MP4 格式），同时缓存最近 N 秒视频用于实时分析
  - AI 面试官根据用户选择的岗位和简历信息，生成第一道面试问题并返回前端
  - 用户听到/看到问题后开始作答，前端持续发送视频流
  - 后端调用 ASR（语音识别）将用户回答转为文本，传递给大模型分析回答质量
  - 大模型生成下一道问题，通过 WebSocket 推送至前端，完成多轮对话交互
  - 面试轮数可配置（默认 6-8 轮），达到指定轮数或用户主动结束时终止面试

**•2.3.2 面试过程录制**：
  - 从 WebSocket 连接建立开始，后端持续接收视频流并写入临时文件
  - 采用切片存储策略：每 30 秒保存为一个视频片段，便于后续处理和分析
  - 面试结束后合并所有视频片段为完整视频文件
  - 视频文件存储路径记录至面试记录表，支持后续回放查看
  - 视频文件设置访问权限：仅用户本人和管理员可查看
  - 视频临时存储管控：保留一定周期（如 30 天）后自动清理，防止隐私泄露

**•2.3.3 本地评测调用**：
  - 用户提交面试后，后端创建评测任务并标记为"分析中"状态
  - 调用本地 AI 分析程序（独立进程或线程池），传入视频文件路径和用户 ID
  - 分析程序异步执行多维度评测，不阻塞主线程
  - 评测进度可查询（0%-100%），前端轮询进度条展示
  - 评测完成后更新面试记录状态为"已完成"，触发报告生成流程

**•2.3.4 自动化评测流程**：
  - **肢体动作分析**：读取视频帧，调用 MediaPipe Pose 模型识别人体关键点，分析坐姿端正度、身体姿态变化、手势动作频率，评价肢体语言是否得体
  - **眼神接触检测**：调用 MediaPipe Face Mesh 模型定位眼部关键点，统计注视摄像头时长占比，评价眼神交流是否充分
  - **手部移动分析**：识别手部关键点轨迹，计算手势丰富度和自然度，评价手势辅助表达效果
  - **情绪状态识别**：调用 DeepFace 模型分析面部表情，识别高兴、悲伤、愤怒、恐惧、惊讶、厌恶、中性七种基本情绪，绘制情绪变化曲线，分析情绪稳定性和自信度
  - 各维度分析结果汇总，计算得分（0-100 分制）并生成结构化评语

**•2.3.5 提交记录留存**：
  - 评测完成后，系统生成完整的面试记录，包含：
    - 评测状态：成功/失败
    - 各维度得分：表达分、逻辑分、自信分、情绪分、肢体分、专业分
    - 分析报告：综合评语、改进建议、雷达图数据
    - 视频回放路径：支持在线播放或下载
    - 问答记录：每一轮的问题、用户回答（ASR 转录文本）、本题分析
  - 所有数据持久化至数据库，支持历史查询和统计分析

### 2.4 AI 智能辅助模块

**•2.4.1 肢体动作分析**：
  - 视频帧预处理： resize、归一化、色彩空间转换
  - 调用 MediaPipe Pose 模型检测人体 33 个关键点坐标
  - 计算关键指标：
    - 坐姿端正度：肩膀连线与水平面夹角、脊柱弯曲度
    - 身体姿态稳定性：身体重心移动幅度、晃动频率
    - 手势动作：手部关键点轨迹长度、手势变化次数、双手协调度
  - 根据预设阈值和评分规则，计算肢体语言得分
  - 生成评语：如"整体坐姿端正，但身体晃动较多，建议保持稳定"

**•2.4.2 眼神接触检测**：
  - 调用 MediaPipe Face Mesh 模型检测 468 个面部关键点，重点定位瞳孔和眼角坐标
  - 计算视线方向向量，判断是否注视摄像头区域
  - 统计指标：
    - 眼神接触时长占比：注视摄像头时间 / 总面试时长
    - 眼神游离次数：视线偏离摄像头的次数
    - 平均单次注视时长：反映专注度
  - 结合行业基准（如优秀面试者眼神接触占比≥60%），计算眼神交流得分
  - 生成评语：如"眼神接触充分，展现了良好的自信和专注度"

**•2.4.3 情绪状态识别**：
  - 从视频中抽取关键帧（如每秒 1 帧）
  - 调用 DeepFace 模型分析面部表情，输出七种情绪概率分布
  - 构建情绪时间序列，绘制情绪变化曲线
  - 计算指标：
    - 情绪稳定性：情绪波动方差（方差越小越稳定）
    - 自信度：中性/高兴情绪占比 vs 恐惧/紧张情绪占比
    - 积极性：积极情绪（高兴、中性）vs 消极情绪（愤怒、悲伤、恐惧）
  - 生成情绪分析报告，包含情绪分布饼图、变化趋势图
  - 生成评语：如"面试过程中保持积极情绪，但在压力问题时出现紧张迹象"

**•2.4.4 智能提问生成**：
  - 初始化阶段：根据用户选择的岗位和简历关键词，从题库中选择首题（通常为破冰题）
  - 每轮对话流程：
    1. 接收用户回答的 ASR 转录文本
    2. 调用讯飞星火大模型 API，传入上下文（岗位信息、历史问答、当前问题、用户回答）
    3. Prompt 设计：要求模型分析回答质量（完整性、准确性、逻辑性），并生成下一道问题
    4. 模型返回 JSON 格式：{"analysis": "本题分析...", "next_question": "下一个问题..."}
    5. 解析返回结果，将 next_question 推送至前端，存储 analysis 至问答记录表
  - 动态调整策略：
    - 若用户回答优秀，提升下一题难度或深入追问
    - 若用户回答较差，降低难度或切换知识点
    - 确保问题覆盖多个考察维度（专业技能、沟通能力、应变能力等）

**•2.4.5 综合评测报告生成**：
  - 数据汇总：收集各维度分析结果（肢体、眼神、情绪、言语、逻辑、专业）
  - 分数计算：
    - 各维度原始分归一化至 0-100 分
    - 加权计算总分（权重可配置，如肢体 20%、表达 25%、逻辑 20%、自信 15%、情绪 10%、专业 10%）
  - 雷达图数据：输出六个维度的得分，供前端绘制雷达图
  - 综合评语生成：
    - 调用大模型，传入各维度详细分析数据
    - Prompt 要求：生成 200-300 字结构化评语，包含优点、不足和改进方向
    - 返回评语文本并存储至报告表
  - 改进建议生成：
    - 针对薄弱项（得分<60 的维度），从建议库中匹配对应建议
    - 建议库按维度和分数段组织，如"眼神接触<60 分：建议练习注视摄像头，可使用眼球追踪训练工具"
    - 输出 JSON 格式建议列表，包含建议标题、详细内容、推荐练习资源
  - 报告下载：支持 PDF 格式（调用 pdfplumber 生成）和 JSON 格式（直接导出原始数据）

### 2.5 数据统计模块

**•2.5.1 个人面试数据统计**：
  - 统计维度：
    - 总面试次数：用户历史完成的面试总数
    - 平均得分：所有面试总分的算术平均值
    - 各维度能力趋势：按时间轴绘制折线图，展示表达、逻辑、自信等维度的变化趋势
    - 岗位匹配度分析：对比用户得分与岗位要求的基准分，计算匹配度百分比
  - 数据可视化：
    - 雷达图：展示最近一次面试的各维度得分
    - 柱状图：对比不同面试的总分
    - 折线图：展示能力成长曲线
  - 支持按岗位、时间范围筛选统计数据

**•2.5.2 评测日志统计**：
  - 系统级统计：
    - 成功面试数：每日/每周/每月完成的面试总数
    - AI 调用记录：调用大模型的次数、成功率、平均耗时、成本统计
    - 系统运行状态：服务可用性、错误率、并发用户数
    - 分析耗时统计：各 AI 模块（肢体分析、情绪识别、ASR 等）的平均耗时分布
  - 性能监控：
    - WebSocket 连接数、断线率、平均延迟
    - 视频处理队列长度、积压情况
    - 数据库查询性能、慢查询日志
  - 异常告警：
    - AI 调用失败率超过阈值时触发告警
    - 系统资源（CPU、内存、磁盘）使用率超限时告警
    - 日志记录和邮件通知管理员

## 三、接口需求

### 3.1 内部接口需求

#### 3.1.1 RESTful API 接口

**• 用户管理接口**：
  - 注册接口：接收用户注册信息，返回用户 ID 和 Token
  - 登录接口：验证用户凭证，签发 JWT Token
  - 个人信息查询/修改接口：获取或更新用户基本信息
  - 头像上传接口：接收图片文件，返回访问 URL
  - 简历上传接口：接收 PDF 文件，返回存储路径
  - 密码修改接口：验证旧密码，更新为新密码哈希值

**• 题库管理接口**：
  - 领域列表接口：获取所有面试领域分类
  - 岗位列表接口：按领域筛选或直接获取所有岗位
  - 题目查询接口：按岗位、难度、标签等多条件筛选题目
  - 题目 CRUD 接口：管理员对题目的新增、查询、编辑、删除操作
  - 批量导入/导出接口：处理 Excel/CSV 格式的题目数据

**• 面试流程接口**：
  - 创建面试接口：初始化面试记录，返回面试 ID
  - 面试状态查询接口：获取当前面试进度和状态
  - 面试历史列表接口：分页查询用户历史面试记录
  - 面试详情接口：获取单次面试的完整信息（视频、问答记录等）
  - 取消面试接口：终止进行中的面试并清理资源

**• 评测报告接口**：
  - 报告生成状态查询接口：轮询 AI 分析进度
  - 报告详情接口：获取评测报告的完整数据（分数、评语、建议）
  - 报告下载接口：支持 PDF 或 JSON 格式下载报告
  - 视频回放接口：获取面试视频的播放地址
  - 数据统计接口：返回个人面试统计数据和趋势分析

**• 系统管理接口**：
  - 用户管理接口：管理员查看用户列表、禁用/启用账号
  - 系统参数配置接口：读取或修改系统运行参数
  - 评测日志查询接口：查看 AI 调用记录和分析耗时统计
  - 数据备份接口：触发数据库备份任务

#### 3.1.2 WebSocket 实时通信接口

**• 视频流传输接口**：
  - 连接建立：前端发起 WebSocket 连接请求，携带面试 ID 和用户 Token
  - 身份验证：后端校验 Token 有效性，拒绝非法连接
  - 视频帧发送：前端按固定频率（15-30fps）发送编码后的视频帧（Base64 或二进制）
  - 心跳检测：双方定期发送 Ping/Pong 消息维持连接活跃
  - 断线重连：网络异常时前端自动尝试重连，恢复上下文

**• 面试问题推送接口**：
  - 初始问题下发：连接建立后，后端发送第一道面试问题
  - 动态问题推送：根据用户回答质量，实时推送下一道问题
  - 面试结束通知：达到指定轮数或用户主动结束时发送终止消息
  - 错误处理：传输失败时重试或降级为文本展示

#### 3.1.3 模块间服务调用接口

**• 业务服务层与 AI 引擎层接口**：
  - 视频分析任务提交：面试服务向 AI 分析模块提交视频文件路径和分析任务类型
  - 分析进度查询：轮询或回调方式获取分析进度（0%-100%）
  - 分析结果返回：AI 模块返回结构化分析数据（JSON 格式）
  - 异步任务队列：使用线程池或消息队列处理并发分析请求

**• 业务服务层与数据持久层接口**：
  - ORM 数据访问：通过 SQLAlchemy 执行数据库 CRUD 操作
  - 事务管理：涉及多表操作时启用事务，支持回滚机制
  - 文件存储接口：封装文件读写操作，统一路径管理和权限控制
  - 缓存接口：热点数据（如题库、用户信息）缓存至内存，提升查询性能

**• AI 引擎内部模块间接口**：
  - 视频帧分发器：将输入视频流按帧拆分，并行分发给肢体分析、情绪识别等模块
  - 结果聚合器：收集各分析模块的输出，整合为统一格式的报告数据
  - 模型加载器：统一管理深度学习模型的加载和释放，避免重复占用内存

### 3.2 外部接口需求

#### 3.2.1 大模型 API 接口

**• 讯飞星火大模型接口**：
  - **接口用途**：智能提问生成、回答质量分析、综合评语生成
  - **调用方式**：HTTP POST 请求，RESTful 风格
  - **请求参数**：
    - API Key 和 APISecret（认证鉴权）
    - Prompt 文本（包含岗位信息、历史问答、用户回答等上下文）
    - 模型版本（如 Spark4.0 Ultra）
    - 温度参数（控制生成随机性，建议 0.7-0.9）
    - 最大生成长度（限制输出 token 数量）
  - **响应格式**：JSON 结构，包含生成的文本内容、使用 token 数、状态码
  - **超时设置**：单次请求超时≤30 秒，支持流式响应降低延迟
  - **错误处理**：
    - 网络异常：指数退避重试策略（最多 3 次）
    - 配额超限：切换备用 API Key 或降级为预设问题库
    - 服务不可用：记录错误日志并返回友好提示

**• 备用大模型接口**（可选）：
  - 支持切换至其他大模型服务商（如百度文心一言、阿里通义千问）
  - 统一封装层设计，屏蔽不同厂商的接口差异
  - 配置文件指定主备服务商优先级

#### 3.2.2 语音识别 API 接口
**• 讯飞 ASR 接口**：
  - **接口用途**：将用户面试回答的音频转换为文本
  - **调用方式**：WebSocket 实时流式识别或 HTTP 文件上传
  - **音频格式**：支持 WAV、MP3、PCM 等常见格式，采样率 16kHz+
  - **识别语言**：中文普通话（支持方言扩展）
  - **响应内容**：识别文本、置信度分数、时间戳标记
  - **性能要求**：识别准确率≥95%，延迟≤2 秒（流式）


### 3.3 接口安全规范

**• 认证与授权**：
  - 所有接口（除登录注册外）需携带 JWT Token 进行身份认证
  - Token 有效期默认 7 天，支持刷新机制延长会话
  - 基于角色的访问控制（RBAC），禁止越权操作
  - 敏感接口（如密码修改、数据删除）需二次验证

**• 数据加密**：
  - HTTPS 传输层加密（TLS 1.2+），防止中间人攻击
  - 敏感字段（密码、手机号）应用层加密后再传输
  - 数据库连接启用 SSL 加密通道

**• 限流与熔断**：
  - 单用户接口调用频率限制（如 100 次/分钟），防止恶意刷接口
  - 大模型 API 调用设置并发上限和超时熔断机制
  - 服务降级策略：核心功能优先，非关键功能可暂时关闭

**• 日志与审计**：
  - 记录所有接口的请求参数、响应结果、耗时、IP 地址
  - 敏感操作（如删除数据、修改密码）单独记录审计日志
  - 日志保留周期≥90 天，支持追溯和故障排查

## 四、非功能需求

### 4.1 性能需求

**• 页面响应时间** ≤ 2 秒，视频流传输延迟 ≤ 500ms

**• AI 分析响应时间** ≤ 120 秒（单场面试全量分析）

**• 大模型提问生成** ≤ 30 秒，支持失败重试、超时熔断机制

**• 并发性能**：支持同时在线用户数 ≥ 1 人，同时面试进行数 ≥ 1 场

### 4.2 安全需求

#### 4.2.1 基础安全

**• 用户密码采用 BCrypt 强哈希加密存储**，迭代次数≥10，杜绝明文存储

**• 接口采用 JWT Token 认证**，防止越权访问

**• 敏感数据传输存储加密**，数据库连接生产环境启用 SSL 加密

#### 4.2.2 视频与数据安全

**• 面试视频存储在沙箱环境**，严格限制访问权限，仅用户本人和管理员可查看

**• 视频临时存储管控**，设置自动清理周期，防止隐私泄露

**• 文件上传格式严格验证**，防止恶意文件上传，限制文件大小

**• 数据库定期备份**，备份数据异地存储

### 4.3 兼容性与易用性

**• 适配 Chrome、Edge、Firefox 等主流 PC 端浏览器**，界面简洁、操作流程直观

**• 视频面试界面友好**，实时反馈清晰，降低用户紧张感

**• 评测报告展示直观**，雷达图、柱状图、文字评语结合，易于理解

### 4.4 可扩展性

**• 支持后续新增面试领域、扩展岗位分类、优化 AI 模型、接入多平台**

**• 模块化设计**，各功能模块解耦，便于后期维护、迭代与二次开发

**• AI 接口可切换**，支持多种大模型服务商，避免单一依赖
