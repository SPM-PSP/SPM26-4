# 模拟面试智能体系统 - 需求分析文档

## 一、项目概述

### 1.1 项目背景与目标

针对传统面试准备中缺乏真实环境模拟、难以自我察觉肢体/表情问题、缺少个性化量化反馈等痛点，依托多模态 AI 技术（计算机视觉、情感计算、大语言模型），打造沉浸式智能化模拟面试平台。系统实现实时视频面试交互、肢体动作智能分析、微表情识别、情绪状态监测、多维度量化评估、个性化改进建议生成等核心功能，为应届毕业生、职场人士、技术人员提供高效、智能的面试能力提升解决方案。

### 1.2 核心业务流程

用户注册登录→完善个人信息→上传简历（可选）→选择面试岗位→进入视频面试→AI 实时提问互动→面试过程全程录制→AI 分析肢体动作/眼神接触/情绪状态→生成多维度评测报告→查看历史面试记录→针对性改进训练

### 1.3 用户角色划分

**• 普通用户**：注册登录、个人信息管理、简历上传、模拟面试、查看评测报告、历史面试回放、下载面试报告

**• 管理员**：题库管理（增删改查）、岗位分类维护、用户管理、系统参数配置、评测日志查看

### 2.2 用户管理模块

#### FR-UM-001 账号注册
**需求描述**：支持用户填写基本信息完成注册流程  
**功能流程**：
  - 用户填写用户名、密码、邮箱、学校、专业、学历等信息
  - 前端校验数据格式，后端检查账号唯一性
  - 密码 BCrypt 加密后存入数据库
  - 支持上传头像和简历文件
  - 注册成功后自动登录或跳转登录页

#### FR-UM-002 账号登录
**需求描述**：支持用户名密码登录，实现身份认证  
**功能流程**：
  - 用户输入用户名和密码
  - 后端验证密码匹配性和账号状态
  - 登录成功生成 JWT Token（有效期 7 天）
  - 后续请求携带 Token 验证身份
  - Token 过期需重新登录或刷新

#### FR-UM-003 个人中心
**需求描述**：提供个人信息管理和数据概览功能  
**功能流程**：
  - 查看和修改个人基本信息
  - 上传/更换头像和简历
  - 展示面试数据统计概览

#### FR-UM-004 权限控制
**需求描述**：基于角色的访问控制，防止越权操作  
**功能流程**：
  - JWT Token 解析用户角色
  - 拦截器校验接口访问权限
  - 普通用户仅访问自身相关接口
  - 管理员专属接口包括题库管理、用户管理等

### 2.3 面试题目管理模块

#### FR-QM-001 题库分类管理
**需求描述**：支持多级分类体系和分类的全生命周期管理  
**功能流程**：
  - 多级分类：领域（一级）→ 岗位（二级）
  - 管理员可新增、编辑、删除分类
  - 支持分类上下线操作
  - 删除前校验是否被题目引用

#### FR-QM-002 题目属性管控
**需求描述**：管理题目基本属性和多维度筛选  
**功能流程**：
  - 题目属性：岗位 ID、难度、内容、答案、标签
  - 支持按岗位、难度、标签筛选
  - 管理员可新增、编辑、删除题目

#### FR-QM-003 智能组卷
**需求描述**：根据岗位自动生成面试题目序列  
**功能流程**：
  - 用户选择岗位后从题库抽取题目
  - 难度梯度：破冰题→专业题→压力题→开放题
  - 考虑标签覆盖度，确保考察全面
  - 支持随机打乱顺序

#### FR-QM-004 题库运维操作
**需求描述**：支持题库的批量运维和操作审计  
**功能流程**：
  - 批量导入导出（Excel/CSV）
  - 题目上下线管理
  - 记录操作日志

### 2.4 在线面试与评测模块

#### FR-IM-001 实时视频面试
**需求描述**：WebSocket 实时音视频交互，AI 自动提问互动  
**功能流程**：
  - 前端请求摄像头权限并建立 WebSocket 连接
  - 按帧率捕获视频流发送至后端
  - AI 生成第一道问题并返回
  - 用户作答时持续发送视频流
  - ASR 转录回答，大模型分析后生成下一题
  - 达到指定轮数或用户主动结束终止面试

#### FR-IM-002 面试过程录制
**需求描述**：全程录制面试视频并安全存储  
**功能流程**：
  - WebSocket 连接建立后开始录制
  - 切片存储（每 30 秒一片段）
  - 面试结束后合并为完整视频
  - 设置访问权限和自动清理周期

#### FR-IM-003 本地评测调用
**需求描述**：异步调用 AI 分析程序进行多维度评测  
**功能流程**：
  - 用户提交面试后创建评测任务
  - 异步调用 AI 分析程序
  - 前端轮询进度条（0%-100%）
  - 完成后触发报告生成

#### FR-IM-004 自动化评测流程
**需求描述**：多模态 AI 分析肢体、眼神、手部、情绪等维度  
**功能流程**：
  - 肢体动作：识别关键点，分析坐姿、姿态、手势
  - 眼神接触：统计注视摄像头时长占比
  - 手部移动：计算手势丰富度和自然度
  - 情绪识别：分析七种基本情绪，绘制变化曲线
  - 汇总各维度结果并计算得分

#### FR-IM-005 提交记录留存
**需求描述**：完整保存面试记录和评测结果  
**功能流程**：
  - 保存评测状态和各维度得分
  - 生成分析报告（评语、建议、雷达图）
  - 记录视频回放路径
  - 保存问答记录（问题、回答、分析）
  - 数据持久化支持历史查询

### 2.5 AI 智能辅助模块

#### FR-AI-001 肢体动作分析
**需求描述**：识别人体姿态并评价肢体语言质量  
**功能流程**：
  - 视频帧预处理和关键点检测
  - 计算坐姿端正度、姿态稳定性、手势动作指标
  - 根据阈值和评分规则计算得分
  - 生成结构化评语

#### FR-AI-002 眼神接触检测
**需求描述**：统计眼神交流情况并评价专注度  
**功能流程**：
  - 检测瞳孔和眼角坐标
  - 计算视线方向向量
  - 统计眼神接触时长、游离次数
  - 结合行业基准计算得分并生成评语

#### FR-AI-003 情绪状态识别
**需求描述**：识别面部表情并分析情绪稳定性  
**功能流程**：
  - 抽取关键帧并分析七种情绪概率分布
  - 构建情绪时间序列
  - 计算情绪稳定性、自信度、积极性指标
  - 生成情绪分析报告和评语

#### FR-AI-004 智能提问生成
**需求描述**：基于大模型动态生成面试问题  
**功能流程**：
  - 根据岗位和简历选择首题
  - ASR 转录用户回答
  - 调用大模型分析回答质量并生成下一题
  - 动态调整难度（优秀则提升，较差则降低）
  - 确保问题覆盖多个考察维度

#### FR-AI-005 综合评测报告生成
**需求描述**：生成多维度量化评估报告和个性化建议  
**功能流程**：
  - 汇总各维度分析结果
  - 归一化分数并加权计算总分
  - 输出雷达图数据
  - 调用大模型生成结构化评语
  - 针对薄弱项匹配改进建议
  - 支持 PDF 和 JSON 格式下载

### 3.2 内部接口需求

#### IR-INT-001 用户管理 RESTful API
**接口描述**：提供用户管理相关的完整 RESTful 接口集  
**接口列表**：
  - 注册接口：接收用户注册信息，返回用户 ID 和 Token
  - 登录接口：验证用户凭证，签发 JWT Token
  - 个人信息查询/修改接口：获取或更新用户基本信息
  - 头像上传接口：接收图片文件，返回访问 URL
  - 简历上传接口：接收 PDF 文件，返回存储路径
  - 密码修改接口：验证旧密码，更新为新密码哈希值

#### IR-INT-002 题库管理 RESTful API
**接口描述**：提供题库管理和运维相关的接口集  
**接口列表**：
  - 领域列表接口：获取所有面试领域分类
  - 岗位列表接口：按领域筛选或直接获取所有岗位
  - 题目查询接口：按岗位、难度、标签等多条件筛选题目
  - 题目 CRUD 接口：管理员对题目的新增、查询、编辑、删除操作
  - 批量导入/导出接口：处理 Excel/CSV 格式的题目数据

#### IR-INT-003 面试流程 RESTful API
**接口描述**：提供面试全流程管理接口  
**接口列表**：
  - 创建面试接口：初始化面试记录，返回面试 ID
  - 面试状态查询接口：获取当前面试进度和状态
  - 面试历史列表接口：分页查询用户历史面试记录
  - 面试详情接口：获取单次面试的完整信息（视频、问答记录等）
  - 取消面试接口：终止进行中的面试并清理资源

#### IR-INT-004 评测报告 RESTful API
**接口描述**：提供评测报告查询和下载相关接口  
**接口列表**：
  - 报告生成状态查询接口：轮询 AI 分析进度
  - 报告详情接口：获取评测报告的完整数据（分数、评语、建议）
  - 报告下载接口：支持 PDF 或 JSON 格式下载报告
  - 视频回放接口：获取面试视频的播放地址
  - 数据统计接口：返回个人面试统计数据和趋势分析

#### IR-INT-005 系统管理 RESTful API
**接口描述**：提供系统管理和运维相关接口  
**接口列表**：
  - 用户管理接口：管理员查看用户列表、禁用/启用账号
  - 系统参数配置接口：读取或修改系统运行参数
  - 评测日志查询接口：查看 AI 调用记录和分析耗时统计
  - 数据备份接口：触发数据库备份任务

#### IR-WS-001 WebSocket 视频流传输
**接口描述**：通过 WebSocket 实现实时视频流传输  
**通信流程**：
  - 连接建立：前端发起 WebSocket 连接请求，携带面试 ID 和用户 Token
  - 身份验证：后端校验 Token 有效性，拒绝非法连接
  - 视频帧发送：前端按固定频率（15-30fps）发送编码后的视频帧
  - 心跳检测：双方定期发送 Ping/Pong 消息维持连接活跃
  - 断线重连：网络异常时前端自动尝试重连，恢复上下文

#### IR-WS-002 WebSocket 面试问题推送
**接口描述**：通过 WebSocket 实时推送面试问题  
**通信流程**：
  - 初始问题下发：连接建立后，后端发送第一道面试问题
  - 动态问题推送：根据用户回答质量，实时推送下一道问题
  - 面试结束通知：达到指定轮数或用户主动结束时发送终止消息
  - 错误处理：传输失败时重试或降级为文本展示

#### IR-MOD-001 业务服务层与 AI 引擎层接口
**接口描述**：业务服务层调用 AI 分析能力的标准接口  
**交互流程**：
  - 视频分析任务提交：面试服务向 AI 分析模块提交视频文件路径和分析任务类型
  - 分析进度查询：轮询或回调方式获取分析进度（0%-100%）
  - 分析结果返回：AI 模块返回结构化分析数据（JSON 格式）
  - 异步任务队列：使用线程池或消息队列处理并发分析请求

#### IR-MOD-002 业务服务层与数据持久层接口
**接口描述**：业务服务层访问数据存储的标准接口  
**功能封装**：
  - ORM 数据访问：通过 SQLAlchemy 执行数据库 CRUD 操作
  - 事务管理：涉及多表操作时启用事务，支持回滚机制
  - 文件存储接口：封装文件读写操作，统一路径管理和权限控制
  - 缓存接口：热点数据（如题库、用户信息）缓存至内存，提升查询性能

#### IR-MOD-003 AI 引擎内部模块间接口
**接口描述**：AI 引擎内部各分析模块间的协作接口  
**模块协作**：
  - 视频帧分发器：将输入视频流按帧拆分，并行分发给肢体分析、情绪识别等模块
  - 结果聚合器：收集各分析模块的输出，整合为统一格式的报告数据
  - 模型加载器：统一管理深度学习模型的加载和释放，避免重复占用内存

### 3.3 外部接口需求

#### IR-EXT-001 Qwen大模型 API
**接口描述**：调用Qwen大模型实现智能问答生成  
**技术规格**：
  - **接口用途**：智能提问生成、回答质量分析、综合评语生成
  - **调用方式**：HTTP POST 请求，RESTful 风格
  - **请求参数**：API Key、APISecret、Prompt 文本、模型版本、温度参数、最大生成长度
  - **响应格式**：JSON 结构，包含生成的文本内容、使用 token 数、状态码
  - **超时设置**：单次请求超时≤30 秒，支持流式响应
  - **错误处理**：网络异常重试（最多 3 次）、配额超限切换备用 Key、服务不可用记录日志

#### IR-EXT-002 备用大模型 API
**接口描述**：备用大模型服务接入方案  
**技术要求**：
  - 支持切换至其他大模型服务商（如百度文心一言、阿里通义千问）
  - 统一封装层设计，屏蔽不同厂商的接口差异
  - 配置文件指定主备服务商优先级

#### IR-EXT-003 语音识别 API（可选）
**接口描述**：语音转文本服务（预留扩展）  
**技术规格**：
  - **接口用途**：将用户面试回答的音频转换为文本
  - **调用方式**：WebSocket 实时流式识别或 HTTP 文件上传
  - **音频格式**：支持 WAV、MP3、PCM 等，采样率 16kHz+
  - **识别语言**：中文普通话
  - **性能要求**：识别准确率≥95%，延迟≤2 秒

### 3.4 接口安全规范

#### IR-SEC-001 认证与授权机制
**安全要求**：
  - 所有接口（除登录注册外）需携带 JWT Token 进行身份认证
  - Token 有效期默认 7 天，支持刷新机制延长会话
  - 基于角色的访问控制（RBAC），禁止越权操作
  - 敏感接口（如密码修改、数据删除）需二次验证

#### IR-SEC-002 数据加密机制
**安全要求**：
  - HTTPS 传输层加密（TLS 1.2+），防止中间人攻击
  - 敏感字段（密码、手机号）应用层加密后再传输
  - 数据库连接启用 SSL 加密通道

#### IR-SEC-003 限流与熔断机制
**安全要求**：
  - 单用户接口调用频率限制（如 100 次/分钟），防止恶意刷接口
  - 大模型 API 调用设置并发上限和超时熔断机制
  - 服务降级策略：核心功能优先，非关键功能可暂时关闭

#### IR-SEC-004 日志与审计机制
**安全要求**：
  - 记录所有接口的请求参数、响应结果、耗时、IP 地址
  - 敏感操作（如删除数据、修改密码）单独记录审计日志
  - 日志保留周期≥90 天，支持追溯和故障排查

### 4.3 安全需求

#### 4.3.1 基础安全

**• 用户密码采用 BCrypt 强哈希加密存储**，迭代次数≥10，杜绝明文存储

**• 数据库定期备份**，备份数据异地存储

**• 适配 Chrome、Edge、Firefox 等主流 PC 端浏览器**，界面简洁、操作流程直观

**• 视频面试界面友好**，实时反馈清晰，降低用户紧张感

**• 评测报告展示直观**，雷达图、柱状图、文字评语结合，易于理解

### 4.5 可扩展性

**• 支持后续新增面试领域、扩展岗位分类、优化 AI 模型、接入多平台**

**• 模块化设计**，各功能模块解耦，便于后期维护、迭代与二次开发

**• AI 接口可切换**，支持多种大模型服务商，避免单一依赖
