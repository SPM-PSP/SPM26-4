## 5. 系统特性

### 5.1 特性 1: 多模态融合分析

#### 5.1.1 描述与优先级

| 属性 | 描述 |
|------|------|
| **标识符** | FEATURE-001 |
| **名称** | 多模态融合分析 |
| **优先级** | 高 |
| **描述** | 系统应同时分析言语、肢体和情绪三个维度的数据，提供全方位量化评估 |

#### 5.1.2 功能性需求

**F-001-01: 言语分析**
- **输入**: 音频流
- **处理**: ASR 转文本 + 流畅度分析 + 语速检测 + 语调分析
- **输出**: `{text: str, fluency_score: float, speed: wpm, tone: str}`

**F-001-02: 肢体分析**
- **输入**: 视频流
- **处理**: 姿态识别 + 眼神接触检测 + 手部移动追踪
- **输出**: `{posture: str, eye_contact: float, hand_movement: float}`

**F-001-03: 情绪分析**
- **输入**: 视频帧
- **处理**: DeepFace 7 种情绪分类
- **输出**: `{emotion: str, confidence: float, history: []}`

#### 5.1.3 质量需求

- **准确性**: 情绪识别准确率 ≥ 85%
- **实时性**: 单帧分析延迟 < 200ms
- **鲁棒性**: 光照变化、遮挡情况下仍能工作

### 5.2 特性 2: 智能评测体系

#### 5.2.1 描述与优先级

| 属性 | 描述 |
|------|------|
| **标识符** | FEATURE-002 |
| **名称** | 6 维雷达图智能评测 |
| **优先级** | 高 |
| **描述** | 系统应生成 6 维雷达图评分和 500 字 + 结构化评语 |

#### 5.2.2 功能性需求

**F-002-01: 6 维评分**
- **维度**: 语言表达、逻辑思维、专业知识、应变能力、仪态仪表、情绪管理
- **评分**: 百分制，加权平均
- **可视化**: 雷达图展示

**F-002-02: 评语生成**
- **结构**: 优点 (30%) + 不足 (40%) + 建议 (30%)
- **字数**: ≥ 500 字
- **个性化**: 基于实际表现，避免模板化

#### 5.2.3 质量需求

- **公正性**: 评分标准一致，无偏见
- **可读性**: 评语通顺，逻辑清晰
- **实用性**: 建议具体可执行

### 5.3 特性 3: 自适应动态提问

#### 5.3.1 描述与优先级

| 属性 | 描述 |
|------|------|
| **标识符** | FEATURE-003 |
| **名称** | LLM 驱动的自适应提问 |
| **优先级** | 高 |
| **描述** | 系统应根据用户回答质量和简历背景，动态调整下一道问题的难度和内容 |

#### 5.3.2 功能性需求

**F-003-01: 策略模式**
- **结合简历模式**: 根据简历经历追问
- **仅回答模式**: 基于当前回答深入
- **仅简历模式**: 针对简历内容提问

**F-003-02: 难度调整**
- **回答优秀** → 提升难度
- **回答困难** → 降低难度或提示
- **动态维持挑战区** (Flow State)

#### 5.3.3 质量需求

- **相关性**: 问题与岗位高度相关
- **连贯性**: 多轮对话上下文连贯
- **多样性**: 避免重复题目
