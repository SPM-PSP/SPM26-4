
# 🎯 Mock Interview 模拟面试智能体系统 - 项目计划书
## 一、 项目概述
本项目旨在开发一款基于**AI大模型 + 语音识别**的轻量化智能模拟面试系统。针对传统面试准备**成本高、无反馈、练习难**的痛点，简化为**纯语音AI面试 + 智能评测报告**核心模式，去掉复杂视频与肢体分析，打造轻量、稳定、易上线的面试训练工具。

### 1.1 项目背景
*   **行业现状与痛点：**
    1.  **真人面试成本高、资源少**：学生与职场人无法高频次模拟训练。
    2.  **自主练习无反馈**：不知道表达是否流畅、逻辑是否清晰。
    3.  **传统工具题库僵化**：固定题目无法根据个人情况灵活追问。
    4.  **视频面试部署复杂**：音视频延迟高、兼容性差、开发难度大。
*   **切入点：**
    本项目采用**“LLM智能对话 + 语音识别 + 结构化评测”**极简架构，**去掉视频/肢体/情绪分析**，只保留**语音面试 + 智能提问 + 报告评分**核心能力，快速落地、稳定可用。

### 1.2 目标人群
1.  **应届毕业生**
    *   特征：缺乏面试经验、易紧张、表达不流畅。
    *   痛点：无人模拟、无专业点评。
    *   价值：免费高频训练，快速提升表达与逻辑。
2.  **职场求职者（1-5年）**
    *   特征：需要面试复盘与表达优化。
    *   痛点：没时间找真人练习。
    *   价值：随时面试、即时出报告。
3.  **高校/社团实训使用**
    *   特征：低成本、易部署、可批量使用。
    *   痛点：复杂系统维护难。
    *   价值：极简稳定，开箱即用。

### 1.3 项目目标（精简版）
*   **业务功能目标：**
    1.  **AI语音模拟面试**：支持选择岗位，AI自动提问、多轮对话。
    2.  **语音转文字与评测**：自动识别回答，给出流畅度、逻辑、完整度评分。
    3.  **生成精简报告**：给出优点、缺点、可落地改进建议。
    4.  **历史记录查看**：保存面试记录与报告，支持复盘。

## 五、 开发模式与工具选型
### 5.1 开发模式：敏捷开发
10周期分为5个Sprint，每2周一次迭代
*   每周站会：同步进度、问题、计划
*   代码审查：合并前互相Review，保证质量

### 5.2 工具选择
*   **项目协作**：飞书
*   **原型设计**：墨刀
*   **代码托管**：Github
*   **接口调试**：Apifox
*   **开发IDE**：VS Code、PyCharm
*   **语音调试**：微信开发者工具/浏览器

### 5.3 平台选择
*   **前端**：微信小程序 / Web页面
*   **后端**：Python + FastAPI
*   **数据库**：MySQL 8.0+
*   **AI能力**：大模型对话 + 在线语音识别
*   **通信**：标准HTTP接口（**去掉WebSocket与视频**）
