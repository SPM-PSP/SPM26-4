# 🎯 Mock Interview 模拟面试智能体系统 - 项目计划书
## 一、 项目概述
本项目旨在开发一款基于**AI大模型 + 计算机视觉 + 情感计算**的智能化模拟面试系统。针对传统面试准备成本高、反馈缺失、肢体表现无法自我评估等痛点，采用**AI智能面试 + 视觉行为分析 + 结构化评测报告**核心模式，打造沉浸式、高还原、可量化评估的面试训练工具。

### 1.1 项目背景
*   **行业现状与痛点：**
    1.  **专业面试指导资源稀缺、成本较高**：学生与职场人群难以获得高频次模拟训练。
    2.  **自主练习缺乏有效反馈**：无法客观判断肢体语言、面部表情、情绪状态与整体表现。
    3.  **传统面试工具功能单一**：无法提供多维度、可视化、量化的综合评估。
    4.  **真人模拟效率低、场景受限**：难以随时随地开展训练，反馈不够客观全面。
*   **切入点：**
    本项目采用**“LLM智能对话 + 计算机视觉分析 + 多模态评测”**架构，聚焦**实时视频面试、肢体动作分析、微表情与情绪识别、智能报告生成**核心能力，实现低成本、高效率、高还原度的面试训练服务。

### 1.2 目标人群
1.  **应届毕业生**
    *   特征：面试经验不足，肢体表现、情绪管理、表达逻辑需要系统训练。
    *   痛点：缺少模拟场景，无法获得专业、客观的行为点评。
    *   价值：提供高频次免费训练，快速提升面试综合表现。
2.  **职场求职者（1-5年）**
    *   特征：有工作经验，需要针对性提升临场状态、肢体语言与情绪控制。
    *   痛点：时间有限，难以安排真人模拟练习。
    *   价值：随时随地训练，快速生成可视化评测与改进方向。
3.  **高校实训与教学使用**
    *   特征：需要标准化、低成本、易部署的综合能力训练工具。
    *   痛点：传统平台仅支持问答，缺少行为与情绪分析能力。
    *   价值：架构完整、功能全面，适合就业指导与综合素养训练场景。

### 1.3 项目目标
*   **业务功能目标：**
    1.  **AI实时视频模拟面试**：支持岗位选择，AI自动提问并完成多轮交互。
    2.  **视觉行为智能分析**：自动识别肢体动作、姿态、眼神接触与情绪状态。
    3.  **生成结构化评测报告**：多维度量化评分，明确优势、不足与可执行改进建议。
    4.  **历史记录与复盘**：保存面试与报告记录，支持回顾与对比提升。
