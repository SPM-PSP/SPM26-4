# 🎯 Mock Interview 模拟面试智能体系统 - 项目计划书
## 一、 项目概述
本项目旨在开发一款基于**AI大模型 + 语音识别**的轻量化智能模拟面试系统。针对传统面试准备成本高、反馈缺失、训练效率低等痛点，采用**AI语音面试 + 智能评测报告**核心模式，打造轻量、稳定、易用的面试训练工具。

### 1.1 项目背景
*   **行业现状与痛点：**
    1.  **专业面试指导资源稀缺、成本较高**：学生与职场人群难以获得高频次模拟训练。
    2.  **自主练习缺乏有效反馈**：无法客观判断表达流畅度、逻辑完整性与回答质量。
    3.  **传统面试工具题库固化**：无法根据用户实际情况进行动态交互与追问。
    4.  **视频类面试系统开发复杂**：对设备、网络与技术要求较高，不利于快速落地。
*   **切入点：**
    本项目采用**“LLM智能对话 + 语音识别 + 结构化评测”**轻量化架构，聚焦**语音面试、智能提问、自动评分、报告生成**核心能力，实现低成本、高效率、稳定可靠的面试训练服务。

### 1.2 目标人群
1.  **应届毕业生**
    *   特征：面试经验不足，表达与逻辑需要系统训练。
    *   痛点：缺少模拟场景，难以获得专业点评。
    *   价值：提供高频次免费训练，快速提升面试能力。
2.  **职场求职者（1-5年）**
    *   特征：有工作经验，需要针对性提升面试表达与应答逻辑。
    *   痛点：时间有限，难以安排真人模拟练习。
    *   价值：随时随地训练，快速生成评测与改进方向。
3.  **高校实训与教学使用**
    *   特征：需要标准化、低成本、易部署的训练工具。
    *   痛点：复杂平台维护成本高，不易规模化使用。
    *   价值：架构简洁、运行稳定，适合教学与实训场景。

### 1.3 项目目标
*   **业务功能目标：**
    1.  **AI语音模拟面试**：支持岗位选择，AI自动提问并完成多轮交互。
    2.  **语音转写与智能评测**：自动将回答转为文字，从流畅度、逻辑性、完整性进行评分。
    3.  **生成结构化评测报告**：明确优势、不足与可执行改进建议。
    4.  **历史记录与复盘**：保存面试与报告记录，支持回顾与对比提升。

## 五、 开发模式与工具选型
### 5.1 开发模式：敏捷开发
项目按10周周期划分为5个Sprint迭代，每2周完成一个阶段目标。
*   每周站会：同步进度、暴露问题、明确本周计划。
*   代码审查：代码合并前进行交叉Review，保障代码质量与规范。

### 5.2 工具选择

*   **产品原型设计**：墨刀
*   **代码托管与版本控制**：Github
*   **API接口调试**：Apifox
*   **开发IDE**：VS Code、PyCharm
*   **前端调试**：微信开发者工具、浏览器调试工具

### 5.3 平台与技术选型
*   **前端**：微信小程序 / Web页面
*   **后端**：Python + FastAPI
*   **数据库**：MySQL 8.0+
*   **AI能力**：大模型对话、在线语音识别
*   **通信方式**：标准HTTP接口
