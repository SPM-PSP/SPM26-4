# 模拟面试服务系统接口文档
## 1. 用户管理
### 1.1 用户注册
- **路径**: `/api/users/register`
- **方法**: POST
- **请求头**:
  Content-Type: application/json
- **请求体**:
```json
{
  "username": "string",
  "password": "string",
  "email": "string",
  "avatar": "string",
  "resume": "string"
}
```
- **响应状态码**:
  200: 成功
  400: 请求参数错误
  500: 服务器内部错误
- **响应体**:
```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user_id": "string",
    "username": "string",
    "email": "string"
  }
}
```

## 2. 面试与评测
### 2.1 获取面试题目
- **路径**: `/api/questions/get`
- **方法**: GET
- **请求头**:
  Authorization: Bearer <token>
- **请求参数**:
  job_title (Query): 面试岗位
  category (Query): 题目类别
- **响应状态码**:
  200: 成功
  400: 请求参数错误
  401: 认证失败
  500: 服务器内部错误
- **响应体**:
```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "questions": [
      {
        "question_id": "string",
        "question_content": "string",
        "difficulty": "string"

}
```

## 3. 文件下载
### 3.1 下载报告
- **路径**: `/api/download/report/{report_id}/download`
- **方法**: GET
- **请求头**:
  Authorization: Bearer <token>
- **请求参数**:
  report_id (Path): 报告ID
- **响应状态码**:
  200: 成功
  400: 请求参数错误
  401: 认证失败
  404: 文件不存在
  500: 服务器内部错误
- **响应体**:
  文件内容（PDF或其他格式）

## 5. 面试Websocket
### 5.1 面试Websocket连接
- **路径**: `/interview/ws`
- **方法**: WebSocket
- **请求参数**:
  id (Query): 用户账号ID
  date (Query): 日期，格式如 2025-07-09 00:00:00
  resume (Query): 简历文件路径
  selected_job (Query): 面试岗位
- **响应状态码**:
  101: 切换协议（连接成功）
  400: 请求参数错误
  500: 服务器内部错误
- **消息格式**:
  请求:
```json
{
  "user_id": "string",
  "question": "string"
}
```
  响应:
```json
{
  "user_id": "string",
  "answer": "string"
}
```

## 示例请求与响应
### 示例请求: 用户注册
请求:
```http
POST /api/users/register HTTP/1.1
Host: example.com
Content-Type: application/json
{
  "username": "testuser",
  "password": "password123",
  "email": "testuser@example.com",
  "avatar": "http://example.com/avatar.jpg",
  "resume": "http://example.com/resume.pdf"
}
```
响应:
```http
HTTP/1.1 200 OK
Content-Type: application/json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user_id": "user123",
    "username": "testuser",
    "email": "testuser@example.com"
  }
}
```
