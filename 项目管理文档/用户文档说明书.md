## 1. 软件技术描述

### 1.1 系统架构概述

本系统采用 **前后端分离 + 分层架构** 设计，整体分为五层：

```
┌──────────────────────────────────────────────────┐
│                前端应用（Vue 3 SPA）                │
│   用户交互 · 视频采集 · 报告可视化 · 状态管理       │
├──────────────────────────────────────────────────┤
│                HTTP REST API + WebSocket          │
├──────────────────────────────────────────────────┤
│         网关 / 路由层（FastAPI + JWT 鉴权）         │
├──────────────────────────────────────────────────┤
│                业务服务层                           │
│  用户管理 · 题库管理 · 面试会话 · 报告生成 · 文件管理 │
├──────────────────────────────────────────────────┤
│                AI 引擎层                            │
│  姿态分析 · 情绪识别 · 眼神检测 · 语音分析 · LLM  │
├──────────────────────────────────────────────────┤
│           数据持久层（MySQL + 本地文件存储）         │
└──────────────────────────────────────────────────┘
```

**核心设计原则**：

| 原则 | 说明 |
|------|------|
| 前后端分离 | 前端 Vue 3 SPA 通过 HTTP/WebSocket 与后端 FastAPI 通信，完全解耦 |
| RESTful API | 所有业务接口遵循 RESTful 规范，统一 JSON 数据格式 |
| 实时通信 | 面试过程采用 WebSocket 全双工通信，支持视频流实时传输 |
| JWT 鉴权 | 用户登录后签发 7 天有效期的 JWT Token，所有接口请求需携带 Token |
| 异步处理 | 视频分析与报告生成采用异步任务模式，避免阻塞用户请求 |

**数据流概要**：

```
用户注册/登录 → JWT Token → 访问系统功能
    │
    ├── 题库练习：选择岗位/难度 → HTTP GET → 返回题目列表
    │
    ├── AI 助手：输入问题 → HTTP POST → LLM 生成回答 → 返回
    │
    ├── 模拟面试：WebSocket 连接 → 视频流上传 → ASR 转录
    │         → LLM 动态出题 → 多轮对话 → 视频合并
    │         → AI 多模态分析 → 评测报告生成
    │
    └── 报告查看：HTTP GET → 获取报告 JSON → 前端可视化渲染
```

### 1.3 主要功能模块介绍

系统围绕"模拟面试 + AI 分析"核心场景，划分为 7 大功能模块：

#### 模块一：用户管理模块

负责用户身份认证与个人信息维护，是整个系统的入口模块。

- **注册**：用户填写账号、密码、昵称、学校、专业、学历、年级、生日等信息完成注册，可选同时上传头像（JPG/PNG/GIF/WebP）和简历（PDF）
- **登录**：账号 + 密码登录，登录成功返回 JWT Token（有效期 7 天），前端存储至 localStorage
- **个人中心**：查看/修改个人信息（昵称、学校、专业、学历、生日），上传/更换头像和简历，修改密码，查看已发布的论坛帖子
- **安全机制**：密码采用 BCrypt 加盐加密存储，接口请求需携带 JWT Token 进行身份验证

#### 模块二：在线题库模块

提供按领域、岗位、难度筛选的结构化面试题库，帮助用户进行针对性练习。

- 领域选择（人工智能、大数据、物联网等 17+ 技术领域）
- 岗位筛选（机器学习工程师、大数据开发工程师等 50+ 岗位）
- 难度分级（简单 / 中等 / 困难）
- 题目卡片展示（含参考答案、用户自填答案区域）
- 一键复制题目或答案到剪贴板（方便粘贴到 AI 助手进一步讨论）

#### 模块三：模拟面试中心（核心模块）

系统的核心功能模块，提供沉浸式视频面试体验。

- **岗位选择**：支持 17 个技术领域、50+ 细分岗位选择，含搜索筛选功能
- **实时视频采集**：基于 WebRTC 获取用户摄像头视频流
- **WebSocket 双向通信**：前端发送视频流 → 后端 ASR 转录 → LLM 分析并生成下一题 → 发送给前端
- **AI 动态提问**：根据简历自动生成个性化追问，问题按"自我介绍 → 专业题 → 综合评估"的难度梯度递进
- **面试录制**：全程录制视频片段（12 秒/段），面试结束后自动合并为完整视频
- **静默检测**：系统自动检测用户回答结束（检测到持续静默），倒计时 3 秒后进入下一题
- **职业百科侧边栏**：提供岗位介绍文章链接，帮助用户了解目标岗位

#### 模块四：AI 评测报告模块

面试结束后自动生成多维度结构化评测报告。

- **7 维度量化评分**：身体姿态、眼神接触、面部情绪、手部动作、言语流畅度、语速、语调
- **可视化图表**：
  - 雷达图：岗位核心能力指标
  - 饼图：姿态分析、眼神接触分布
  - 柱状图：情绪分布
  - 横向柱状图：流畅度分析
  - 环形图 / 评分卡片：语调、语速指标
- **综合评语**：AI 根据分析数据生成结构化评语（优点总结 + 改进建议 + 岗位匹配度）
- **报告管理**：历史报告列表查看、报告详情查看、报告 PDF 下载
- **视频回放**：支持回放面试视频

#### 模块五：AI 助手模块

独立的 AI 对话服务，支持用户随时进行面试相关咨询。

- 基于通义千问（Qwen3.5-plus）大模型的多轮对话
- 内置信使（System Prompt）："你是一名专业的AI助手，擅长回答各种问题"
- 预设建议问题（如"如何准备大数据岗位面试？"）
- 支持 Markdown 格式渲染（代码块、列表、加粗等）
- "面试锦囊"侧边栏：提供精选文章与学习资源推荐

#### 模块六：经验分享论坛模块

社区化的面试经验交流平台。

- **帖子浏览**：支持按分类筛选（热门、最新、大数据、物联网、AI）、关键词搜索
- **发布帖子**：填写标题、内容、分类，一键发布（数据持久化到 localStorage）
- **帖子详情**：查看完整内容，支持动态路由（`/post/:id`）
- **收藏功能**：收藏感兴趣的帖子（数据持久化到 localStorage）
- **"我的发布"**：在个人中心查看自己发布的所有帖子

#### 模块七：学习资源推荐模块

结构化整合外部学习资源，帮助用户系统性提升技能。

- 热门推荐课程（Coursera、DataCamp、Udemy 等平台）
- 视频课程专区（B站、YouTube 优质资源）
- 学习社区与论坛（GitHub、Stack Overflow、知乎 等）
- 一键跳转外部链接

### 1.4 关键技术特性

| 特性 | 实现方式 |
|------|---------|
| **实时视频处理** | WebRTC 采集 → MediaRecorder 编码 WebM → WebSocket 切片传输（12 秒/片） |
| **多模态 AI 分析** | 视频帧分发器 → 并行处理（姿态 + 情绪 + 眼神 + 手部）→ 结果聚合器统一输出 |
| **智能组卷** | LLM 分析简历 + 历史对话 → 动态生成适配题目 → 难度梯度：破冰题 → 专业题 → 压力题 → 开放题 |
| **异步报告生成** | 面试结束后后台异步调用 AI，前端轮询进度，避免 HTTP 超时 |
| **跳帧检测优化** | 核心指标（眼神对视）每帧检测，非核心指标（坐姿）每 5 帧检测一次，前端延迟 ≤ 450ms |
| **暗光鲁棒性** | AI 路由层嵌入直方图均衡化等对比度增强预处理算法 |
| **JWT 安全鉴权** | Token 有效期 7 天，接口层面校验 accountID 与 Token 一致性，防止横向越权 |
| **密码安全** | BCrypt 加盐加密存储，数据库不保存明文密码 |
| **CORS 跨域支持** | 后端配置 CORS 中间件，允许 `localhost:8080` 等指定源访问 |
| **文件权限隔离** | 头像/简历/视频/报告按 accountID 分目录存储 |

错误信息：error: Microsoft Visual C++ 14.0 or greater is required

**解决方案**：
```bash
# 方案 A：使用 mysql-connector-python（项目已默认使用此驱动）
pip install mysql-connector-python

# 方案 B：安装 Visual C++ Build Tools
# 下载地址：https://visualstudio.microsoft.com/visual-cpp-build-tools/
# 安装时勾选"Desktop development with C++"
```

#### 问题 2：MediaPipe 安装失败或运行报错

```
错误信息：ImportError: cannot import name '...' from 'mediapipe'
```

**解决方案**：
```bash
# 方案 A：安装特定版本
pip install mediapipe==0.10.14

# 方案 B（macOS Apple Silicon）：
pip install mediapipe-silicon

# 方案 C（Linux）：确保系统已安装必要库
sudo apt install libgl1-mesa-glx libglib2.0-0
```

#### 问题 3：MySQL 连接被拒绝

```
错误信息：Can't connect to MySQL server on 'localhost:3306' (10061)
```

**解决方案**：
1. 确认 MySQL 服务已启动（Windows：服务管理器 → MySQL80 → 启动）
2. 检查端口是否被占用：`netstat -ano | findstr 3306`
3. 确认防火墙未阻止 3306 端口
4. 确认数据库连接字符串中的用户名和密码正确

#### 问题 4：DeepFace / TensorFlow 加载模型超时

```
错误信息：Connection timeout when downloading model weights
```

**解决方案**：
```bash
# 方案 A：设置代理
set HTTP_PROXY=http://你的代理地址:端口
set HTTPS_PROXY=http://你的代理地址:端口

# 方案 B：手动下载模型文件
# DeepFace 模型权重默认存储在 ~/.deepface/weights/ 目录
# 可参考 DeepFace 官方文档手动下载放置
```

#### 问题 5：前端 npm install 失败（node-sass / sass 相关）

```
错误信息：Error: Cannot find module 'node-sass'
```

**解决方案**：
```bash
# 项目使用 sass（Dart Sass），不是 node-sass
npm install sass sass-loader --save-dev

# 清理缓存后重新安装
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

#### 问题 6：WebSocket 连接失败（前端面试功能不可用）

```
错误信息：WebSocket connection to 'ws://localhost:8000/interview/ws' failed
```

**解决方案**：
1. 确认后端服务已启动在 8000 端口
2. 检查 WebSocket 路由是否注册（查看 main.py 中 `Interview_websocket.router` 是否已 include）
3. 检查浏览器是否支持 WebSocket（Chrome 90+ / Edge 90+ / Firefox 88+）
4. 如使用代理（Nginx），需配置 WebSocket 代理支持

### 3.2 各功能模块操作流程

#### 3.2.1 用户注册与登录

**注册流程**：

1. 访问系统首页，点击顶部导航栏"注册"按钮，或点击登录页"注册"链接
2. 填写注册表单：
   - 账号（必填，用于登录的唯一标识）
   - 密码（必填，建议使用 8 位以上含字母+数字的组合密码）
   - 昵称（必填，系统显示名称）
   - 学校名称（必填）
   - 专业（必填）
   - 学历（必填，下拉选择：高职/本科/研究生/博士）
   - 年级（必填，格式如"本科二年级"）
   - 生日（选填，日期选择器）
   - 头像文件（选填，支持 JPG/PNG/GIF/WebP）
   - 简历文件（选填，仅支持 PDF）
3. 点击"注册"按钮提交
4. 注册成功后跳转至登录页面

**登录流程**：

1. 访问登录页面（`/sign-in`）
2. 输入账号和密码
3. 点击"登录"按钮
4. 登录成功后自动跳转到主页（Dashboard）

**退出登录**：在个人中心页面，点击"退出登录"按钮。

#### 3.2.2 在线题库操作

1. 在侧边栏点击"在线题库"进入题库页面
2. 选择筛选条件：
   - **技术领域**：下拉选择（人工智能、大数据、物联网、前端开发 等 17 个领域）
   - **岗位**：根据所选领域显示对应岗位（如领域选择"大数据"后，岗位可选"大数据开发工程师""数据架构师"等）
   - **难度**：简单 / 中等 / 困难
3. 点击"更新题目"按钮加载题目列表
4. 浏览题目卡片：
   - 每张卡片包含：题号、难度标签、题目内容
   - 点击"复制题目问问AI"可将题目一键复制到剪贴板
   - 在"你的回答"文本框中输入自己的答案
   - 点击"显示答案"查看参考答案
   - 点击"复制回答"将自己的答案复制到剪贴板

#### 3.2.3 模拟面试中心操作（核心功能）

**准备阶段**：

1. 在侧边栏点击"模拟面试中心"进入面试页面
2. 在搜索框中输入关键词（如"前端"）快速筛选领域/职位
3. 点击领域标签选择面试领域（如"人工智能"——标签高亮显示）
4. 选择具体的面试岗位（如"机器学习测试工程师"）
5. 点击"进入面试"按钮
   - 系统会自动检查简历状态
   - 如果尚未上传简历，面试仍可进行，但 AI 将使用通用题库出题

**面试阶段**：

1. 页面切换到面试界面：
   - 左侧：用户摄像头视频画面
   - 右侧：面试问题展示区域
2. 点击"开始面试"按钮，系统将：
   - 建立 WebSocket 连接
   - 摄像头开始采集视频
   - AI 发出第一个问题（通常是"请简单做一下自我介绍"）
3. 对着摄像头回答问题
   - 系统自动检测回答结束（静音检测）
   - 检测到回答结束后，倒计时 3 秒
   - AI 自动分析回答内容并生成下一道问题
4. 面试过程中：
   - 视频自动切片上传（12 秒/段）
   - 右侧实时显示当前问题
   - 如需要，可点击"结束面试"提前终止
5. 面试结束后：
   - 所有视频片段自动合并
   - 后台异步进行 AI 多模态分析
   - 等待几分钟后，在个人中心查看评测报告

**界面控件说明**：

| 控件 | 功能 |
|------|------|
| "开始面试"按钮 | 启动面试流程（摄像头开始录制 + WebSocket 连接） |
| "结束面试"按钮 | 提前终止面试会话 |
| "返回选择"按钮 | 回到岗位选择页面（面试启动前可用） |
| 静默倒计时提示 | 检测到用户回答结束后，显示"将在 X 秒后分析回答..." |
| 职业百科侧边栏 | 点击左下角"不知道选什么职业？"可查看岗位介绍资料 |

#### 3.2.4 AI 助手操作

1. 在侧边栏点击"AI 助手"进入对话页面
2. 首次进入显示预设建议问题，点击任一建议问题即可开始对话
3. 在底部输入框输入问题（如"大数据岗位面试常见考点有哪些？"）
4. 按 Enter 键发送（Shift+Enter 换行）
5. AI 回答以气泡形式显示在对话区域
6. 支持多轮对话，AI 会记住上下文（如追问"那第二个考点呢？"）
7. 点击右侧"面试锦囊"按钮可展开精选面试资源推荐

#### 3.2.5 查看评测报告

1. 面试结束后，进入个人中心页面
2. 在"我的报告"区域查看历史面试记录列表
3. 点击某条记录进入报告详情页
4. 报告页面展示：

| 区域 | 展示内容 |
|------|---------|
| 顶部信息栏 | 视频编号、面试时间、应聘职位 |
| 综合评语 | AI 生成的结构化总结与改进建议 |
| 岗位能力雷达图 | 6 项核心能力指标可视化对比 |
| 身体姿态分析 | 饼图（坐姿/低头/正常等分布） + 评分 + 评语 |
| 面部情绪分析 | 柱状图（7 种情绪分布） + 评分 + 评语 |
| 眼神接触分析 | 饼图（注视/游离分布） + 评分 + 评语 |
| 言语流畅度分析 | 横向柱状图 + 评分 + 评语 |
| 语调分析 | 环形评分图 + 综合评分 |
| 语速分析 | 语速指标 + 评分 |

5. 点击顶部"下载报告 (PDF)"按钮可导出 PDF 文件
6. 点击"返回个人中心"回到个人中心页面

#### 3.2.6 分享论坛操作

1. 在侧边栏点击"分享论坛"进入社区页面
2. **浏览帖子**：默认显示所有帖子，支持：
   - 顶部分类筛选（热门/最新/我的收藏/大数据/物联网/人工智能）
   - 搜索框输入关键词搜索帖子标题
3. **发布帖子**：点击右上角"分享面经/信息"按钮
   - 填写标题（如"我的大数据开发岗春招上岸总结"）
   - 填写内容（支持多行文本）
   - 选择分类标签
   - 点击"发布"提交
4. **帖子详情**：点击任意帖子标题进入详情页，查看完整内容
5. **收藏帖子**：点击帖子下方的收藏按钮（星标图标），收藏后在"我的收藏"分类中可查看

#### 3.2.7 个人中心操作

1. 在侧边栏点击"个人中心"进入

**个人信息管理**：
- 查看个人信息（昵称、账号、学校、专业、学历、生日）
- 点击"编辑资料"进入编辑模式，修改后点击"保存更改"
- 点击头像可更换头像（选择本地图片文件上传）
- 点击"修改密码"进行密码变更

- 查看面试历史记录

### 3.3 典型使用场景示例

#### 场景一：应届毕业生准备校招面试

**角色**：计算机专业大四学生，准备应聘大数据开发岗位  
**操作流程**：

1. 注册账号，填写学校、专业（计算机科学）、学历（本科）、年级（本科四年级）
2. 上传个人简历（PDF 格式）
3. 进入"在线题库"→ 选择"大数据"领域 → "大数据开发工程师"岗位 → "中等"难度 → 浏览题目并自测

5. 充分练习后，进入"模拟面试中心"→ 选择"大数据"→"大数据开发工程师"→ 点击"进入面试"
6. 完成面试（约 5-8 轮问答）
7. 面试结束后等待几分钟，进入个人中心查看评测报告

9. 针对性在"在线题库"中复习对应难度的题目
10. 多次练习后再次面试，对比历史报告中的评分提升情况

#### 场景二：职场人士跳槽前自评

**角色**：3 年工作经验的后端开发工程师，准备应聘 AI 算法岗  
**操作流程**：

1. 登录系统，完善个人信息和最新简历
2. 进入"模拟面试中心"→ 选择"人工智能"→"机器学习测试工程师"
3. 进行一场完整面试
4. 查看评测报告，重点关注：
   - 言语流畅度（表达逻辑是否清晰）
   - 眼神接触（面试中是否有足够的目光交流）
   - 身体姿态（坐姿是否端正自信）
   - 综合评语（AI 给出的改进建议）
5. 根据报告中的弱项指标，针对性练习
6. 在"分享论坛"中搜索目标公司的面经帖子
7. 发布自己的面经经验，与社区用户交流

#### 场景三：高校实训教学使用

**角色**：就业指导课教师，安排学生进行模拟面试训练  
**操作流程**：

1. 教师和学生各自注册账号
2. 学生在课堂或课后进入系统：
   - 上传简历
   - 选择与专业对口的岗位
   - 完成模拟面试

6. 学生在"分享论坛"中交流面试心得

### 3.4 操作注意事项

| 编号 | 注意事项 | 详细说明 |
|------|---------|---------|
| 1 | 摄像头与麦克风权限 | 首次使用模拟面试功能时，浏览器会弹出摄像头和麦克风权限请求，**必须点击"允许"**，否则无法进行视频面试。 |
| 2 | 浏览器兼容性 | 视频面试功能依赖 WebRTC 和 MediaRecorder API，请使用 **Chrome 90+、Edge 90+ 或 Firefox 88+** 浏览器。不支持 IE 和旧版 Safari。 |
| 3 | 面试环境光线 | AI 视觉分析对光线有一定要求。请确保面试环境**光线充足、面部清晰可见**，避免背光和过于昏暗的场景。 |
| 4 | 面试背景简洁 | 复杂的背景可能影响 MediaPipe 姿态检测准确率，建议使用**纯色或简洁的背景**。 |
| 5 | 网络稳定性 | 面试过程中需要持续上传视频流，建议使用**稳定的 Wi-Fi 或有线网络**。网络不稳定可能导致 WebSocket 断连。 |
| 6 | 面试时长 | 单次面试通常包括 5-8 轮问答，全程约 5-10 分钟。请预留足够的时间完成完整面试。 |
| 7 | 报告生成等待 | 面试结束后，AI 分析需要一定时间（通常 1-3 分钟），其间可在个人中心稍等后查看报告。 |
| 8 | 简历格式 | 简历上传仅支持 **PDF 格式**，单文件大小建议不超过 10MB。 |
| 9 | 头像格式 | 头像上传支持 **JPG、PNG、GIF、WebP** 格式，建议尺寸 200×200 像素以上。 |
| 10 | 退出登录 | 使用公共电脑时，请务必在使用完毕后**退出登录**，防止他人访问您的个人信息和面试记录。 |
| 11 | Token 有效期 | JWT Token 有效期 7 天，过期后需要重新登录。 |
| 12 | 数据存储限制 | 论坛帖子和收藏列表存储在浏览器的 **localStorage** 中，清除浏览器数据会导致这些信息丢失。 |

## 5. 常见问题解答

### 5.1 账户相关

**Q1：忘记密码怎么办？**

> 目前系统尚未提供自助找回密码功能。如果您忘记了密码，请联系系统管理员协助重置。

**Q2：可以修改账号名称吗？**

> 账号名称（accountID）是用户的唯一标识，注册后不支持修改。如需更换，请使用新账号重新注册。

**Q3：注册时提示"账户已存在"怎么办？**

> 说明该账号已被注册。请尝试使用其他账号名称，或检查是否已注册过（可尝试登录）。

**Q4：登录后提示"Token 过期"怎么办？**

> JWT Token 有效期为 7 天。过期后系统会自动跳转到登录页面，重新输入账号密码登录即可。

### 5.2 面试相关

**Q5：面试时看不到自己的摄像头画面怎么办？**

> 请按以下步骤排查：
> 1. 检查浏览器是否已授权摄像头权限（浏览器地址栏左侧锁图标 → 允许摄像头）
> 2. 确认摄像头未被其他应用占用（如 Zoom、Teams 等请先关闭）
> 3. 尝试刷新页面后重新授权
> 4. 如使用外接摄像头，检查设备是否正确连接并被系统识别

**Q6：面试过程中 WebSocket 连接断开了怎么办？**

> WebSocket 断开通常由网络不稳定导致。建议：
> 1. 切换到更稳定的网络（有线网络优于 Wi-Fi）
> 2. 刷新页面重新开始面试
> 3. 如果问题持续，检查防火墙或代理设置是否阻止了 WebSocket 连接

**Q7：面试结束后多久能看到报告？**

> AI 分析过程通常需要 1-3 分钟。面试结束后，进入个人中心稍等片刻，刷新页面即可看到最新报告。如果长时间未生成，可能是 AI 服务暂时不可用，请联系管理员。

**Q8：为什么我的面部情绪分析显示"中性"为主？**

> 这是正常现象。面试场景下，大多数人的自然表情偏向"中性"（neutral）。AI 分析的是您在面试中情绪的稳定性和自信度，而非要求您必须有丰富的表情变化。适度的中性表情在面试中通常是加分项。

**Q9：AI 生成的评分是否绝对准确？**

> AI 评分基于计算机视觉和深度学习模型，提供的是量化参考数据，帮助企业用户了解自身表现的趋势和大致水平。评分受光线、摄像头质量、网络条件等因素影响，建议关注各维度的相对变化趋势，而非绝对分数值。

### 5.3 题库相关

**Q10：题库中的参考答案是标准答案吗？**

> 参考答案仅供参考，为题目提供了一个解答方向。实际面试中，面试官更看重您的思维过程、表达逻辑和实际经验，而非是否与"标准答案"一致。建议将参考答案作为知识点查漏补缺的工具。

**Q11：题库支持自定义添加题目吗？**

> 当前版本仅支持浏览系统预置题目。如需添加特定方向或公司的题目，请联系管理员进行题库扩充。

### 5.4 报告相关

**Q12：报告中的雷达图各项指标代表什么？**

> 雷达图的 6 项指标由 `vocation_signs` 表根据面试岗位动态配置。例如，大数据开发岗的核心指标可能是：Hadoop 生态知识、实时计算能力、数据仓库设计、算法基础、项目经验、软技能。每个岗位的指标维度可能不同。

**Q13：如何下载面试评测报告？**

> 进入报告详情页（报告查看页面），点击顶部绿色的"下载报告 (PDF)"按钮，系统将自动生成并下载 PDF 文件。PDF 文件包含完整的报告内容和可视化图表。

**Q14：报告数据会保存多久？**

> 报告数据存储在 MySQL 数据库中，只要管理员不手动删除，数据会永久保存。视频文件存储在服务器本地文件系统中，管理员可能根据存储空间情况设置自动清理策略。

### 5.5 论坛相关

**Q15：我发布的帖子存在哪里？会被其他人修改吗？**

> 论坛帖子和收藏数据存储在您浏览器的 localStorage 中。其他用户无法看到或修改您的帖子，您也无法看到其他用户的帖子（除非你们使用同一浏览器）。如需社区交流，请通过其他渠道分享您的帖子内容。

**Q16：清除浏览器缓存后帖子会丢失吗？**

> 是的。因为帖子数据存储在浏览器的 localStorage 中，清除浏览器数据会导致帖子丢失。建议将重要的帖子内容备份保存到本地文件。

### 5.6 技术相关

**Q17：系统支持哪些浏览器？**

> 推荐使用以下浏览器的最新版本：
> - Google Chrome 90+
> - Microsoft Edge 90+
> - Mozilla Firefox 88+
>
> **不推荐**：Internet Explorer（已停止支持）、Safari 旧版本（WebRTC 支持有限）

**Q18：手机浏览器可以使用吗？**

> 系统前端基于响应式 Bootstrap 5 设计，大部分页面在手机浏览器上可以正常浏览。但模拟面试的视频采集功能依赖桌面级 WebRTC 支持，建议在**电脑端浏览器**上进行模拟面试。

**Q19：面试视频文件存储在哪里？**

> 视频文件存储在服务器的 `DataFile/Video/` 目录下，按 `accountID/视频文件名` 的层级组织。用户通过报告详情页或下载接口访问视频文件。
